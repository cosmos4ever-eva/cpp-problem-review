## 题意

给定 `n` 个正整数，从中选择尽量少的数字，使这些数字进行按位或运算后的结果等于：

```cpp
(1 << k) - 1
```

输出最少选择数量；如果不存在满足条件的方案，输出 `-1`。

## 目标值为什么是 `(1 << k) - 1`

`1 << k` 表示把二进制数字 `1` 向左移动 `k` 位。例如 `k == 3` 时：

```text
1 << 3       = 1000（二进制）
(1 << 3) - 1 = 0111（二进制）
```

因此：

```cpp
(1 << k) - 1
```

可以生成一个低 `k` 位全部为 `1` 的目标值。判断所有要求的位是否都已经被覆盖，应写成：

```cpp
currentor == (1 << k) - 1
```

不能写成 `currentor << k == 1`；后者是在移动 `currentor` 的二进制位，含义完全不同。

## 搜索状态

原始代码使用：

```cpp
void DFS(int idx)
```

其中 `idx` 表示当前准备考虑 `a[idx]`。另外使用两个全局状态：

```cpp
currentor  // 当前已经选择的数字按位或的结果
len        // 当前已经选择的数字数量
```

到达相同的 `idx` 时，不同路径的 `currentor` 和 `len` 可能不同，因此它们也是搜索状态的一部分。这里通过全局变量和回溯维护，也可以把它们作为参数按值传入下一层。

## 每个数字的两种选择

### 选择当前数字

每考虑一个数，就把它与当前结果进行按位或运算：

```cpp
currentor = currentor | a[idx];
len++;
DFS(idx + 1);
```

按位或会把两个数字对应二进制位上的 `1` 合并起来。已经变成 `1` 的位不会因为后续继续按位或而回到 `0`，所以可以把它理解为不断覆盖目标中的二进制位。

### 不选择当前数字

不选择 `a[idx]` 时，`currentor` 和 `len` 都不变，只把下标移到下一个数字：

```cpp
DFS(idx + 1);
```

因此每个数字形成“选择”和“不选择”两个分支，是标准的二叉决策树。

## 为什么达到目标后可以立即返回

```cpp
if (currentor == (1 << k) - 1) {
    min_num = min(min_num, len);
    return;
}
```

此时当前路径已经覆盖全部目标位。继续选择其他数字只会让 `len` 增大，不可能得到数量更少的方案，所以更新答案后可以立即返回。

如果已经处理完全部数字却仍未达到目标，就直接返回：

```cpp
if (idx == n) {
    return;
}
```

## `tmp` 为什么必须是局部变量

选择当前数字之前，需要保存本层原来的按位或结果：

```cpp
int tmp = currentor;
```

递归结束后用它恢复现场：

```cpp
currentor = tmp;
```

`tmp` 必须定义在 DFS 内部。每一层函数调用都会得到自己独立的局部 `tmp`，所以内层递归修改和返回时，外层保存的旧值仍然存在。

如果把 `tmp` 设置成全局变量，所有递归层会共享同一个值：

1. 外层把自己的旧 `currentor` 存入全局 `tmp`；
2. 进入内层后，内层又覆盖全局 `tmp`；
3. 返回外层时，`tmp` 已经不再是外层保存的值；
4. 外层无法正确恢复现场，后面的“不选择”分支会受到污染。

此外，按位或通常不能通过一次相反运算撤销。例如两个数字可能在同一位上都为 `1`，因此不能简单使用异或或减法恢复。最稳妥的做法就是在每一层用局部变量保存完整旧值。

## 答案与无解判断

题目数据范围中最多选择 `16` 个数字，因此使用：

```cpp
int min_num = 17;
```

表示暂时没有找到答案。每次成功覆盖目标时更新：

```cpp
min_num = min(min_num, len);
```

搜索结束后，如果它仍然等于 `17`，说明没有任何子集满足要求，输出 `-1`。

## 可选剪枝

如果当前已经选择的数量不小于已有最优答案，继续搜索不可能变得更优：

```cpp
if (len >= min_num) {
    return;
}
```

该剪枝不影响正确性，只减少无意义的递归。整理版代码将它与 `idx == n` 的终止条件合并。

## 复杂度

每个数字都有选择和不选择两种情况，因此：

- 时间复杂度：最坏为 `O(2^n)`；
- 递归栈空间复杂度：`O(n)`。

## 主要易错点

1. 低 `k` 位全部为 `1` 的目标值是 `(1 << k) - 1`。
2. 每选择一个数字，都要执行 `currentor | a[idx]`，并让选择数量增加 `1`。
3. DFS 的当前数组下标是 `idx`，不能在函数中使用只存在于输入循环里的 `i`。
4. 全局 `currentor` 和 `len` 在选择分支结束后必须恢复，才能继续搜索不选择分支。
5. 保存旧按位或结果的 `tmp` 必须是每层独立的局部变量，不能被更深的递归调用覆盖。
6. `17` 是建立在 `n <= 16` 上的无解标记；数据范围变化时应相应调整。
