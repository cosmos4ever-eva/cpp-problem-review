## 题意

给定序列 `{1, 2, ..., n}`，从中选择恰好 `k` 个数字，按照字典序输出所有不重复的组合。组合内部的数字按照升序排列。

## 使用子集的“选或不选”思想

一个组合不能重复使用同一个数字，因此可以依次处理 `1` 到 `n`，对每个数字只作一次决定：选择或不选择。

```cpp
output.push_back(idx);   // 选择 idx
DFS(idx + 1,k - 1);
output.pop_back();

DFS(idx + 1,k);         // 不选择 idx
```

两条分支都会继续处理 `idx + 1`，因此已经处理过的数字不会再次出现：

- 选择 `idx` 时，剩余需要选择的数量从 `k` 变为 `k - 1`。
- 不选择 `idx` 时，剩余数量仍然是 `k`。

这与生成所有子集的二叉决策树相同，只是本题只保存元素数量恰好符合要求的结果。

## 两个参数的含义

```cpp
void DFS(int idx,int k)
```

- `idx` 表示当前正在决定是否选择的数字。
- `k` 表示当前还需要选择几个数字。

例如 `DFS(4, 2)` 表示数字 `1、2、3` 已经决定完毕，现在从数字 `4` 开始处理，并且还需要选择两个数字。

## 两个终止条件都不能删除

### 已经选够：保存答案

```cpp
if(k == 0){
    result.push_back(output);
    return;
}
```

当 `k == 0` 时，说明已经选够要求的数字，这是成功的叶节点，需要保存当前组合。

### 数字用完但没有选够：直接返回

```cpp
if(idx == n + 1){
    return;
}
```

当 `idx == n + 1` 且 `k > 0` 时，说明 `1` 到 `n` 已经全部处理完，但组合仍未达到要求。这是失败分支，只能结束，不能保存任何内容。

因此不能删掉对 `idx` 的判断，否则程序会继续选择 `n + 1、n + 2……`，无法正确结束。

## 为什么必须先判断 `k == 0`

如果最后选择的数字恰好是 `n`，下一次递归会同时进入：

```text
k == 0
idx == n + 1
```

这是已经完成的合法组合，应该保存答案。因此必须先判断成功条件 `k == 0`，再判断失败条件 `idx == n + 1`。

如果顺序反过来，程序会先因为数字用完而返回，漏掉所有最后一个数字为 `n` 的组合。

## 为什么没有重复并且满足字典序

`idx` 每次只会增加，程序不会回头处理更小的数字。因此每个组合内部自然升序，也不会产生 `{1,2}` 与 `{2,1}` 这种代表同一个组合的两种排列。

搜索时先进入“选择当前较小数字”的分支，再进入“不选择”的分支，所以包含较小数字的组合先产生，结果自然满足题目要求的字典序，不需要额外排序。

## 复杂度

- 搜索树最坏有 `O(2^n)` 个状态。
- 一共有 `C(n,k)` 个合法组合，保存和输出结果需要 `O(k * C(n,k))` 时间与空间。
- 当前递归路径和 `output` 最长为 `O(n)`。

## 主要易错点

1. 本题沿用子集的“选或不选”二叉树，但通过参数 `k` 限制每个组合的元素数量。
2. 选择 `idx` 后递归参数是 `DFS(idx + 1, k - 1)`；不选择时是 `DFS(idx + 1, k)`。
3. `k == 0` 表示成功，需要保存答案；`idx == n + 1` 且仍未选够表示失败，只返回而不输出。
4. `k == 0` 必须放在 `idx == n + 1` 前面，才能保存恰好在最后一个数字处完成的组合。
5. 选择分支返回后必须执行 `output.pop_back()`，再进入不选择分支。
