## 题意

给定序列 `{1, 2, ..., n}`，输出它的所有子集。先输出元素较少的子集；元素个数相同时，按照字典序从小到大输出。空集用空行表示。

## 参考解法：每个元素选或不选

`solution.cpp` 使用最基础的子集 DFS。`DFS(idx)` 表示当前准备决定数字 `idx` 是否放入子集，每个数字都有两条分支：

```cpp
temp.push_back(idx);  // 选择 idx
DFS(idx + 1);
temp.pop_back();

DFS(idx + 1);         // 不选择 idx
```

第一条分支把 `idx` 加入 `temp`，递归返回后用 `pop_back()` 恢复现场；第二条分支不加入 `idx`，直接处理下一个数字。

## 终止条件

需要依次决定 `1` 到 `n` 是否被选择。当 `idx == n + 1` 时，说明所有数字都已经处理完，`temp` 就是一个完整子集：

```cpp
if (idx == n + 1) {
    result.push_back(temp);
    return;
}
```

这里必须立即 `return`，否则还会继续处理不存在的数字。

## 搜索树示例

当 `n = 2` 时，每一层分别决定一个数字：

```text
是否选择 1
├── 选择 1
│   ├── 选择 2   → {1, 2}
│   └── 不选择 2 → {1}
└── 不选择 1
    ├── 选择 2   → {2}
    └── 不选择 2 → {}
```

这种写法只需要一个参数 `idx`，逻辑统一为“选择当前元素”或“不选择当前元素”，因此更容易作为枚举所有子集的基础模板。

## 为什么还需要排序

DFS 生成结果的顺序不是题目要求的“元素数量优先、字典序次之”，所以生成全部子集后使用：

```cpp
sort(result.begin(), result.end(), cmp);
```

比较函数先比较子集大小：

```cpp
return a.size() < b.size();
```

大小相同时使用 `return a < b;`。`vector` 的 `<` 会按照元素从前到后进行字典序比较，因此不需要自己再写一层循环。

## 你的原始解法

`original.cpp` 采用另一种正确方法：外层依次生成大小为 `0、1、...、n` 的子集，内部使用 `DFS(start, depth)` 枚举固定长度的组合。

- `depth` 管“还要选择几个元素”。
- `start` 管“当前位置从哪个数字开始选择”。
- 选择 `j` 后调用 `DFS(j + 1, depth - 1)`。
- `j <= n - depth + 1` 保证剩余数字足够，是有效剪枝。

例如 `DFS(3, 2)` 表示还要选择两个元素，并且当前位置只能从 `3` 开始选。

你的方法能直接按题目要求的顺序生成答案，不需要排序，效率更高；参考答案的“选或不选”结构更直观、更适合先学习子集 DFS。两种方法都保留在本题目录中。

## 复杂度

- DFS 一共生成 `2^n` 个子集，复制和保存子集需要 `O(n * 2^n)` 时间与结果空间。
- 参考解法还要排序 `2^n` 个子集；排序进行 `O(2^n log(2^n))` 次比较，每次字典序比较最坏需要检查 `O(n)` 个元素。
- 单条递归路径和 `temp` 最长为 `n`。

## 主要易错点

1. “选或不选”写法要让两条分支都进入 `DFS(idx + 1)`，只有选择分支需要先加入元素再恢复现场。
2. 到达 `idx == n + 1` 后保存答案并立即返回。
3. DFS 的自然生成顺序不符合本题要求，需要在最后按照“长度优先、字典序次之”排序。
4. `vector` 可以直接使用 `<` 进行字典序比较。
5. 在原始组合写法中，`depth` 与 `start` 的职责不同，不能只用其中一个代替另一个。
