## 题意

给定序列 `{1, 2, ..., n}`，输出它的所有子集。先输出元素较少的子集；元素个数相同时，按照字典序从小到大输出。空集用空行表示。

## 整体思路

外层循环依次生成大小为 `0、1、...、n` 的子集：

```cpp
for(int i = 0;i <= n;i++){
    DFS(1,i);
}
```

每个 `i` 都对应一棵新的搜索树，这棵树只生成恰好包含 `i` 个元素的子集。先枚举较小的 `i`，就能保证元素少的子集先输出。`i` 从 `0` 开始是为了生成空集。

## `depth` 和 `start` 的不同职责

当前函数定义为：

```cpp
void DFS(int start,int depth)
```

- `depth` 表示当前还剩几个元素需要选择，因此递归到下一层时使用 `depth - 1`，当 `depth == 0` 时得到一个完整子集。
- `start` 表示当前位置最小可以选择哪个数，因此当前层从 `start` 开始枚举。选择 `j` 后，下一层调用 `DFS(j + 1, depth - 1)`。

例如生成大小为 `2` 的子集时，初始状态是 `DFS(1, 2)`。如果当前选择了 `2`，下一层状态就是 `DFS(3, 1)`：还需要选择一个元素，并且只能从 `3` 开始选择。

所以，`depth` 管“还要选几个”，`start` 管“接下来从哪里选”。`start` 并不是没有用；如果只保留 `depth`，程序就不知道上一层选到了哪个值，可能产生降序结果或重复子集。

## 状态定义必须前后一致

本题把 `depth` 定义为“剩余需要选择的数量”，所以三处写法必须互相对应：

```cpp
if(depth == 0)              // 已经不需要再选
DFS(j + 1, depth - 1);      // 选择一个后，剩余数量减一
```

也可以把参数定义为固定不变的“目标总长度”，此时应使用 `output.size() == targetDepth` 判断结束，并且递归时不能减少 `targetDepth`。两种定义都可以，但不能把两套逻辑混在一起。

## 当前层的枚举范围

```cpp
for(int j = start;j <= n - depth + 1;j++)
```

当前还需要选择 `depth` 个数，所以选择 `j` 后，区间 `[j, n]` 至少要有 `depth` 个可选数字。这给出上界：

```text
j <= n - depth + 1
```

例如 `n = 5、depth = 2` 时，`j` 最大只能取 `4`，因为还需要把 `5` 留给下一层。这个上界属于剪枝；写成 `j <= n` 通常也能得到正确答案，但会进入一些注定无法凑够元素的无效分支。

## 为什么不会重复且满足顺序

选择 `j` 后从 `j + 1` 继续选择，可以同时保证：

1. 每个子集内部严格递增；
2. 同一个元素不会被重复选择；
3. `{1, 2}` 和 `{2, 1}` 不会被当成两个不同子集；
4. 当前层按从小到大枚举 `j`，所以相同大小的子集按字典序产生。

## 复杂度

- 一共有 `2^n` 个子集，保存所有答案至少需要 `O(2^n)` 次处理。
- 若把保存各个子集所复制的元素也计算在内，时间和结果空间均为 `O(n * 2^n)`。
- 单条递归路径和 `output` 最长为 `n`。

## 主要易错点

1. 明确 `depth` 表示目标总深度还是剩余深度，并让终止条件与递归参数的变化保持一致。
2. 外层循环枚举子集大小，每个大小会生成一棵搜索树；为了包含空集，应从 `0` 枚举到 `n`。
3. `start` 控制当前位置的候选值范围，选择 `j` 后应传入 `j + 1`，不能写成 `start + 1`。
4. 当前还需选择 `depth` 个数时，枚举上界为 `n - depth + 1`。
5. 用 `push_back` 做出选择，递归返回后用 `pop_back()` 恢复现场。
