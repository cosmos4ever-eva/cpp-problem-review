# 06 元求和

- 总题号：034
- 日期：2026-09-13
- 类型：深度优先搜索、二叉决策树、累计状态、回溯、`set`
- 状态：AI 辅助完成
- 建议复习：2026-09-14

## 题意

给定 `n` 个整数。求和之前，每个数字都可以保留原值，也可以变成它的相反数。输出所有可能得到的和，每个不同的和只输出一次，并按从小到大的顺序输出。

例如输入：

```text
1 2
```

四种正负号选择为：

```text
+1 +2 =  3
+1 -2 = -1
-1 +2 =  1
-1 -2 = -3
```

去重并排序后得到 `-3、-1、1、3`。

## 搜索状态

```cpp
void DFS(int idx)
```

`idx` 表示当前准备处理 `a[idx]`。全局变量：

```cpp
int output;
```

表示当前递归路径已经得到的累计和。

相同的 `idx` 可能对应不同的累计和。例如处理完第一个数字 `1` 后，两条路径都会进入 `idx == 1`，但它们的累计和分别为 `1` 和 `-1`。因此累计和也是搜索状态的一部分，必须通过全局变量配合回溯维护，或者作为 DFS 参数向下传递。

全局 `int` 变量会被初始化为 `0`；整理版把变量命名为 `currentSum` 并显式写成 `0`，使含义更清楚。

## 每个数字的两种选择

对于当前数字 `a[idx]`，搜索树分成两条分支。

保留原数：

```cpp
output += a[idx];
DFS(idx + 1);
output -= a[idx];
```

变成相反数：

```cpp
output -= a[idx];
DFS(idx + 1);
output += a[idx];
```

两次递归之后都要执行相反操作恢复现场，使后续分支从进入本层之前的累计和出发。

## 终止条件

```cpp
if (idx == n) {
    result.insert(output);
    return;
}
```

当 `idx == n` 时，说明所有数字都已经决定了正负号。此时 `output` 就是一条完整路径得到的和，将它加入结果集合。

## 为什么使用 `set<int>` 而不是 `vector<vector<int>>`

以前的组合、排列问题需要输出具体选择路径，所以使用：

```cpp
vector<vector<int>> result;
vector<int> output;
```

其中 `output` 保存一条完整路径，`result` 保存所有路径。

本题最后输出的是每条路径产生的一个“和”，不是完整路径。因此路径状态和结果元素都变成单个整数：

```cpp
int output;
set<int> result;
```

题目还要求相同的和只输出一次，并按从小到大的顺序输出。`set` 恰好会自动去重，并按升序遍历，所以不需要再手动调用 `sort` 和 `unique`。

## `set` 的插入和遍历

`set` 没有 `push_back`，因为它不存在“在末尾追加”的概念。添加元素应使用：

```cpp
result.insert(output);
```

`set` 也没有 `operator[]`，不能写 `result[i]`。输出时需要循环遍历：

```cpp
for (int x : result) {
    cout << x << '\n';
}
```

这里最后一个结果后面的 `\n` 只是结束最后一行，不会产生额外的空白行，符合“每个值占一行”的要求。

## 复杂度

每个数字都有保留原值和变为相反数两种选择，因此搜索树最多有 `2^n` 个叶节点。

设最终有 `M` 个不同的和：

- 每次向 `set` 插入的时间复杂度为 `O(log M)`；
- 总时间复杂度为 `O(2^n log M)`；
- 递归栈深度为 `O(n)`；
- 结果集合占用 `O(M)` 空间。

## 主要易错点

1. `idx` 只表示处理到哪个数字；累计和也会随分支变化，必须作为搜索状态维护。
2. 本题保存的是最终和值，不是完整路径，所以累计状态使用 `int`，结果使用 `set<int>`。
3. `set` 使用 `insert` 添加元素，没有 `push_back`。
4. `set` 不支持下标访问，必须使用范围 `for` 或迭代器遍历。
5. 两个分支递归返回后都要恢复累计和，否则一个分支的选择会污染另一个分支。
6. 如果数据范围使所有数字的绝对值之和可能超过 `int`，累计和与结果集合的元素类型都应改成 `long long`。

## 通用模板

[template.cpp](template.cpp) 是这类题的可复用模板，适用于以下特征：

1. 每个元素都有两种选择；
2. 每条路径只需维护一个累计整数；
3. 只输出不同的最终值；
4. 最终值需要自动按升序输出。

模板的固定结构是：

```text
到达叶节点 -> 把累计值 insert 到 set
选择一 -> 修改状态 -> 递归 -> 恢复状态
选择二 -> 修改状态 -> 递归 -> 恢复状态
```
