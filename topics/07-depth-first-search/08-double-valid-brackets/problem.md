## 题意

使用 `{`、`}`、`[`、`]` 四种符号，生成所有长度为偶数 `n` 的合法括号字符串。每个右括号必须与对应类型的左括号匹配，并且所有括号必须正确嵌套。结果按照字典序输出。

## 为什么单一的数量差不够

只有一种括号时，可以用：

```text
dif = 左括号数量 - 右括号数量
```

只要保证 `dif >= 0`，就能确保每个右括号左边都有可匹配的左括号。

出现两种括号后，只知道“还有几个左括号没有匹配”已经不够，还必须知道最近一个未匹配左括号的类型。例如前缀：

```text
[{
```

此时有两个左括号尚未匹配，但下一个右括号只能是 `}`，不能是 `]`。如果只记录数量 `2`，就无法作出这个判断。

因此需要设置一个栈，保存当前所有尚未匹配的左括号。

## 栈中保存什么

代码使用：

```cpp
vector<char> leftBrackets;
```

把它当作栈使用：

- 遇到左括号时，使用 `push_back` 压入栈顶；
- 需要生成右括号时，使用 `back` 查看栈顶类型；
- 匹配栈顶左括号后，使用 `pop_back` 弹出；
- 递归返回时，再把弹出的左括号压回去恢复现场。

括号的正确嵌套遵循“后打开的括号先关闭”，正好对应栈的后进先出顺序。

## 搜索状态

```cpp
void DFS(int idx)
```

其中：

- `idx` 表示已经生成的字符数量；
- `output` 保存当前括号字符串；
- `leftBrackets` 保存尚未匹配的左括号及其嵌套顺序；
- `leftCount` 表示当前路径一共使用了多少个左括号。

输入的 `n` 是最终字符串长度，不是括号对数，所以总共只能使用 `n / 2` 个左括号。

## 添加左括号

只有左括号总数还没有达到 `n / 2` 时，才能继续添加左括号：

```cpp
if (leftCount < n / 2) {
    output.push_back('[');
    leftBrackets.push_back('[');
    leftCount++;

    DFS(idx + 1);

    leftCount--;
    leftBrackets.pop_back();
    output.pop_back();
}
```

添加 `{` 的过程完全相同，只是压入栈中的字符改为 `'{'`。

这里添加的是单个 `char`，所以必须使用单引号 `'['`、`'{'`，不能使用字符串字面量 `"["`、`"{"`。

## 栈顶限制右括号类型

如果栈顶是 `[`，当前只能添加 `]`：

```cpp
if (!leftBrackets.empty() && leftBrackets.back() == '[') {
    output.push_back(']');
    leftBrackets.pop_back();
    DFS(idx + 1);
    leftBrackets.push_back('[');
    output.pop_back();
}
```

如果栈顶是 `{`，当前只能添加 `}`：

```cpp
if (!leftBrackets.empty() && leftBrackets.back() == '{') {
    output.push_back('}');
    leftBrackets.pop_back();
    DFS(idx + 1);
    leftBrackets.push_back('{');
    output.pop_back();
}
```

例如当前前缀为 `[{` 时，栈从底到顶是 `[`、`{`。栈顶为 `{`，因此只能先生成 `}`；等它匹配并弹出后，栈顶才重新变为 `[`，随后才能生成 `]`。这样可以得到 `[{}]`，但不会生成错误的 `[{]}`。

## 终止条件必须阻止超长字符串

当生成长度达到 `n` 时，无论栈是否为空，都不能再添加字符：

```cpp
if (idx == n) {
    if (leftBrackets.empty()) {
        result.push_back(output);
    }
    return;
}
```

只有栈为空时才保存答案，但 `return` 必须放在外层 `idx == n` 判断中。

错误写法：

```cpp
if (idx == n && leftBrackets.empty()) {
    result.push_back(output);
    return;
}
```

如果 `idx == n` 时栈不为空，这种写法不会返回，代码还会继续添加字符，生成超过题目要求长度的无效分支。

## 为什么结果已经符合字典序

整理版按照字符编码顺序尝试：

```text
'[' < ']' < '{' < '}'
```

也就是依次尝试：

1. `[`；
2. 合法时尝试 `]`；
3. `{`；
4. 合法时尝试 `}`。

DFS 会先完整搜索较小字符开头的子树，因此结果自然符合普通字符串字典序，不需要额外调用 `sort`。

## 复杂度

令 `m = n / 2`。长度为 `n` 的合法单类型括号结构有第 `m` 个卡特兰数种，每一对括号又可以独立选择 `[]` 或 `{}` 两种类型，所以合法输出数量为：

```text
Catalan(m) * 2^m
```

每个答案长度为 `n`，仅输出全部答案就需要与总输出规模成正比的时间和空间。递归栈深度为 `O(n)`。

## 主要易错点

1. 输入的 `n` 是字符串总长度，终止条件是 `idx == n`，左括号最多使用 `n / 2` 个。
2. 两种括号不能只记录左右括号数量差，还必须用栈保存未匹配左括号的类型和嵌套顺序。
3. 添加右括号时必须检查栈非空，并且只能添加与栈顶匹配的右括号。
4. 右括号分支弹出栈顶后，递归返回时必须把原左括号压回栈中。
5. `idx == n` 时必须停止搜索；栈为空则保存，否则直接放弃，不能继续生成更长字符串。
6. `vector<char>::push_back` 接收单个字符，应使用单引号。
