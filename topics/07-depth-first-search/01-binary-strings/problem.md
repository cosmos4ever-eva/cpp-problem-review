## 题意

在长度为 `n` 的数组中填写 `0` 或 `1`，按照字典序从小到大输出所有可能的 01 串。

每个位置都有两种选择，因此一共有 `2^n` 个结果。

## DFS 状态的含义

```cpp
void DFS(int idx)
```

`idx` 表示当前准备填写的位置，也表示 `output` 中已经填入了多少个数字。进入 `DFS(idx)` 时应保持：

```text
output.size() == idx
```

本层先选择 `0` 并递归处理下一位，再选择 `1` 并递归处理下一位。因为总是先走 `0` 分支，所以叶节点按照字典序产生。

## 优先规定终止条件

写 DFS 时应先确定“什么时候得到一个完整答案”。本题在已经填写 `n` 个位置时到达叶节点：

```cpp
if(idx == n){
    result.push_back(output);
    return;
}
```

终止条件中包含两件事：

1. 保存或输出当前完整答案；
2. 立即 `return`，结束当前层递归。

如果保存答案后没有返回，程序还会继续向 `output` 中添加数字并调用 `DFS(idx + 1)`，从而越过合法深度并无限递归。

## 先画搜索树

写递归前可以先画出 `n = 2` 的搜索树：

```text
空
├── 0
│   ├── 00
│   └── 01
└── 1
    ├── 10
    └── 11
```

每个非叶节点都执行两组相同动作：

```text
加入选择 → 递归进入下一层 → 删除选择
```

对应代码为：

```cpp
output.push_back(0);
DFS(idx + 1);
output.pop_back();
```

然后把选择改成 `1` 再执行一次。递归调用的位置应放在“入栈”和“出栈”之间，因为下一层需要看到当前层已经做出的选择。

## `push_back` 与 `pop_back`

```cpp
output.push_back(0);
```

表示在 `vector` 末尾加入一个具体值。

```cpp
output.pop_back();
```

表示删除末尾现有的元素。它只删除最后一个元素，因此括号中不需要也不能填写具体值。

`pop_back()` 的作用是恢复进入当前分支之前的状态。处理完以 `0` 开头的子树后删除 `0`，才能在相同位置继续尝试 `1`。

## 二维 `vector` 的输出

`result` 的类型是：

```cpp
vector<vector<int>>
```

标准输出流没有定义如何一次打印整个二维 `vector`，所以不能写：

```cpp
cout << result;
```

需要使用两层循环：

```cpp
for(int i = 0;i < result.size();i++){
    for(int j = 0;j < result[i].size();j++){
        cout << result[i][j];
    }
}
```

外层 `i` 控制第几个 01 串，内层 `j` 控制当前串中的第几个数字。内层循环末尾必须写 `j++`；误写成 `i++` 会让 `i` 在内层不断增大并造成 `result[i]` 越界。

## 复杂度

- 一共有 `2^n` 个结果，每个结果包含 `n` 个数字。
- 保存和输出所有结果需要 `O(n * 2^n)` 时间。
- `result` 保存全部答案，需要 `O(n * 2^n)` 空间；递归路径 `output` 最长为 `n`。

## 主要易错点

1. 写 DFS 时优先确定终止条件；到达叶节点后完成保存或输出，并立即 `return`。
2. 可以先画搜索树，从叶节点反推每条边上的“加入选择、递归、撤销选择”动作。
3. `pop_back()` 只删除 `vector` 最后的元素，括号中不填写具体值。
4. 二维 `vector` 不能直接使用 `cout` 输出，需要两层循环逐个打印元素。
5. 内层输出循环控制的是 `j`，循环末尾应写 `j++`，不能误写为 `i++`。
