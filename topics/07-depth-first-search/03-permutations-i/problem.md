## 题意

给定序列 `{1, 2, ..., n}`，按照字典序输出它的所有全排列。每个排列中的数字不能重复使用。

## DFS 思路

搜索树的每一层负责填写排列中的一个位置。对于当前位置，依次尝试 `1` 到 `n` 中所有尚未使用的数字：

```cpp
for(int i = 1;i <= n;i++){
    if(exist[i] == true) continue;

    output.push_back(i);
    exist[i] = true;
    idx++;

    DFS(idx);

    output.pop_back();
    exist[i] = false;
    idx--;
}
```

其中：

- `output` 保存当前已经填写的排列。
- `exist[i]` 表示数字 `i` 是否已经出现在当前排列中。
- `idx` 表示当前准备填写的位置。

完成一条分支后，需要同时恢复 `output`、`exist[i]` 和 `idx`，才能继续尝试当前位置的其他数字。

## 终止条件必须与初始参数统一

当前代码从下面的位置开始：

```cpp
DFS(1);
```

这里把 `idx` 理解为“当前准备填写第几个位置”。填写完第 `n` 个位置后，下一次递归进入 `idx == n + 1`，所以终止条件是：

```cpp
if(idx == n + 1)
```

也可以从 `DFS(0)` 开始，把 `idx` 理解为“已经填写了几个位置”，这时填写完全部位置后是 `idx == n`，终止条件就应改为：

```cpp
if(idx == n)
```

两种写法都正确，关键是初始值、参数含义和终止条件必须采用同一套逻辑：

```text
DFS(1)  对应  idx == n + 1
DFS(0)  对应  idx == n
```

## 为什么判断要写在循环内部

错误形式是：

```cpp
for(int i = 1;i <= n && exist[i] == false;i++)
```

如果遇到一个已经使用的数字，整个 `for` 循环会立即终止，后面尚未使用的数字也没有机会被尝试。

正确做法是让循环始终枚举 `1` 到 `n`，再在循环内部跳过已经使用的数字：

```cpp
for(int i = 1;i <= n;i++){
    if(exist[i] == true) continue;
}
```

`continue` 只跳过本轮循环，然后继续检查下一个数字；它不会结束整个循环。

## `exist` 为什么要开 `n + 1` 位

代码直接使用数字 `1` 到 `n` 作为 `exist` 的下标，因此需要：

```cpp
exist.resize(n + 1);
```

这样合法下标是 `0` 到 `n`。如果只开 `n` 位，合法下标最大为 `n - 1`，访问 `exist[n]` 会越界。

## 为什么自然满足字典序

每一层都按照 `1、2、...、n` 的顺序尝试未使用的数字。因此较小的数字会先出现在第一个不同的位置，生成结果本身就是字典序，不需要额外调用 `sort`。

## 复杂度

- 一共有 `n!` 个全排列，每个排列包含 `n` 个数字，保存和输出需要 `O(n * n!)` 时间。
- `result` 保存所有答案，需要 `O(n * n!)` 空间。
- 当前递归路径、`output` 和 `exist` 需要 `O(n)` 额外空间。

## 主要易错点

1. `DFS(1)` 与终止条件 `idx == n + 1` 对应；`DFS(0)` 与终止条件 `idx == n` 对应。
2. 跳过已使用数字的判断不能放进 `for` 的循环条件，否则遇到第一个已使用数字就会提前结束整个循环。
3. 应在循环内部使用 `if(exist[i]) continue;`，只跳过当前数字并继续尝试后面的数字。
4. 使用 `1` 到 `n` 作为下标时，`exist` 必须创建 `n + 1` 个元素。
5. 回溯时既要从 `output` 删除当前数字，也要把 `exist[i]` 恢复为 `false`。
