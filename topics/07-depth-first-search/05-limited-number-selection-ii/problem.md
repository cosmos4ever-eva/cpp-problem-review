## 题意

给定 `n` 个互不相同的正整数，从中选择若干个数。每个数可以选择任意次，求数字之和恰好为 `k` 的方案数。只有顺序不同的选择属于同一种方案。

## 搜索状态

```cpp
void DFS(int idx)
```

`idx` 表示当前正在处理 `input[idx]`。对于这个数字，搜索树分成两条分支：

1. 再选择一次当前数字；
2. 不再选择当前数字，开始处理下一个数字。

初始调用 `DFS(0)`，表示从第一个数字开始处理。

## 选择当前数字：`DFS(idx)`

```cpp
output.push_back(input[idx]);
sum += input[idx];
DFS(idx);
output.pop_back();
sum -= input[idx];
```

题目允许同一个数字选择任意次，所以选择 `input[idx]` 后，递归参数仍然是 `idx`：

```cpp
DFS(idx);
```

这样下一层仍然可以继续选择当前数字。虽然参数 `idx` 没有改变，但这不是相同的递归状态，因为 `sum` 已经增加，`output` 中也多了一个数字。

输入全部是正整数，因此每次选择后 `sum` 都会严格增大，最终一定会到达 `sum == k` 或 `sum > k`，不会无限递归。这里可以理解为重复选择这条路线主要由 `sum` 控制递归终止。

## 不再选择当前数字：`DFS(idx + 1)`

```cpp
DFS(idx + 1);
```

这条分支表示以后都不再使用 `input[idx]`，开始考虑下一种数字。因此 `idx` 必须加一。

程序不会再回到更小的下标，所以同一个方案只会按照不下降的数字顺序生成。例如能够生成 `{2,2,3}`，但不会再生成只有顺序不同的 `{2,3,2}`。

这里可以理解为“不再选择”这条路线由 `idx` 不断增大推进，并通过 `n` 限制能够处理的数字种类范围。

## 两种终止条件

### 和恰好为目标值

```cpp
if(sum == k) {
    result.push_back(output);
    return;
}
```

当前选择已经构成一种合法方案，保存后立即返回。所有输入都是正数，继续添加数字只会让总和超过 `k`。

### 总和超过目标，或者数字已经用完

```cpp
if(sum > k || idx == n) return;
```

- `sum > k`：正数只会让总和继续增大，不可能再回到 `k`。
- `idx == n`：所有不同的数字都处理完了，不能再访问 `input[idx]`。

必须先判断 `sum == k`，再判断 `idx == n`。如果恰好在处理完最后一种数字时达到目标和，应该先保存这个成功方案。

## 与普通“选或不选”的区别

普通子集问题中每个数字最多选择一次：

```cpp
选择：DFS(idx + 1);
不选：DFS(idx + 1);
```

本题允许当前数字重复选择，因此改成：

```cpp
选择当前数字：DFS(idx);
不再选择当前数字：DFS(idx + 1);
```

这仍然是一棵二叉决策树，只是“选择”分支会停留在当前数字上。

## 复杂度

搜索状态数量与 `n`、目标值 `k` 以及输入数字大小有关。由于每个数字最多选择 `k / input[idx]` 次，搜索是有限的；最坏情况下方案数量和搜索分支可能很大。

当前代码把每种具体方案保存在 `result` 中，因此空间还与方案总数及每个方案的长度有关。

## 主要易错点

1. 当前数字可以重复选择，所以选择分支调用 `DFS(idx)`，不能写成 `DFS(idx + 1)`。
2. `DFS(idx)` 中参数虽然不变，但正整数使 `sum` 严格增大，递归能由 `sum == k` 或 `sum > k` 终止。
3. 不选择分支实际表示“以后都不再选择当前数字”，因此要调用 `DFS(idx + 1)`。
4. `idx` 是数组下标，应使用 `idx == n` 判断是否处理完全部数字，不能与目标和值 `k` 比较。
5. `sum == k` 是成功状态，必须放在 `sum > k || idx == n` 前面判断。
