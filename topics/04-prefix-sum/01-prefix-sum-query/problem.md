# 01 前缀和

- 状态：独立完成
- 建议复习：2026-09-07

## 题意

给定一个由 `n` 个正整数组成的序列，再给出 `k` 次查询。每次查询给出一个正整数 `m`，要求输出序列前 `m` 个数之和。

数据范围：`1 <= n, k <= 10^4`，每个正整数不超过 `10^4`，`1 <= m <= n`。

## 核心思路

如果每次查询都重新累加前 `m` 个数，最坏情况下需要 `O(nk)` 时间。可以先用一次扫描预处理前缀和，之后每次查询只需访问一个位置。

整理版采用长度为 `n + 1` 的前缀和数组：

```cpp
prefix[0] = 0;
prefix[i] = prefix[i - 1] + value;
```

这里 `prefix[i]` 表示原序列前 `i` 个数之和，因此查询前 `m` 个数时直接输出 `prefix[m]`。

## 两种下标定义

原始代码使用长度为 `n` 的数组：

```cpp
sum[i] = sum[i - 1] + a[i];
```

此时 `sum[i]` 表示前 `i + 1` 个数之和，所以查询前 `m` 个数时必须访问 `sum[m - 1]`。

整理版在最前面增加一个值为 `0` 的位置，让“前几个数”与前缀数组下标一致：

```text
prefix[0] = 前 0 个数之和
prefix[1] = 前 1 个数之和
prefix[m] = 前 m 个数之和
```

## 复杂度

- 预处理时间：`O(n)`。
- 每次查询时间：`O(1)`，全部查询共 `O(k)`。
- 空间：`O(n)`。

## 主要易错点

1. **先确定 `sum[i]` 的含义。** 如果它表示前 `i + 1` 个数之和，查询前 `m` 个数时要向前偏移一位，使用 `sum[m - 1]`。
2. **推荐预留 `prefix[0] = 0`。** 此时 `prefix[i]` 表示前 `i` 个数之和，查询时直接使用 `prefix[m]`，也方便以后计算任意区间和。
3. **注意累计和的类型。** 本题使用 `int` 不会溢出，但为了适应更大的数据范围，整理版使用 `long long`。
4. **不要每次查询重新循环求和。** 前缀和的意义就是一次预处理、多次快速查询。

## 对原始代码的整理

原始代码逻辑正确，并且已经正确使用 `sum[m - 1]`。整理版省略了不再需要的原数组，改用带前导零的前缀和定义，并使用 `long long` 保存累计结果。

## 复习问题

2. 为什么 `prefix[0] = 0` 能减少下标错误？
3. 如果要查询原数组下标区间 `[left, right]` 的和，应该如何使用 `prefix`？
