## 题意

给定一个长度为 `n` 的整数数组，寻找最小下标 `i`，使得分别对 `a[0...i]` 和 `a[i+1...n-1]` 升序排序后，结果与对整个数组升序排序相同。

数据范围：`1 <= n <= 10^5`，数组元素属于 `int` 范围。

## 核心思路

两部分分别排序后能组成整个数组的有序结果，当且仅当左半部分的所有元素都不大于右半部分的所有元素。等价条件是：

```text
左半部分最大值 <= 右半部分最小值
```

从右向左预处理后缀最小值 `min_index[i]`，表示区间 `a[i...n-1]` 的最小值。随后从左向右用一个变量维护 `a[0...i]` 的最大值，并寻找第一个满足下面条件的位置：

```cpp
max_index <= min_index[i+1]
```

第一个满足条件的位置就是最小分割下标。

## 后缀最小值

最后一个位置没有右侧元素，因此先单独初始化：

```cpp
min_index[n-1] = a[n-1];
```

然后从 `n - 2` 开始向左计算：

```cpp
for(int i = n - 2;i >= 0;i--){
    min_index[i] = min(a[i],min_index[i+1]);
}
```

必须从 `n - 2` 开始，因为计算时会访问 `i + 1`；如果从 `n - 1` 开始，就会访问下标 `n` 而越界。

## 为什么最后返回 `n - 1`

循环只检查 `0` 到 `n - 2`，因为这些位置会把数组分成左右两个非空部分。如果一直找不到满足条件的分割点，将整个数组作为左半部分、右半部分为空一定可行，因此返回 `n - 1`。

这个返回语句必须写在循环外。写在循环内会在第一次判断失败时提前返回，无法继续检查后面的分割位置。

## 复杂度

- 时间：`O(n)`，分别进行一次从右向左和一次从左向右的扫描。
- 空间：`O(n)`，用于保存后缀最小值数组。

## 主要易错点

1. **后缀数组从右向左建立。** 先初始化最后一个位置，再从 `n - 2` 开始遍历，避免访问 `min_index[n]`。
2. **判断条件是左侧最大值不大于右侧最小值。** 即 `max_index <= min_index[i + 1]`。必须使用 `<=`，并且右侧从当前分割点的下一个位置 `i + 1` 开始；不能写成会越界的 `min_index[n + 1]`。
3. **默认答案写在循环外。** 若一直没有找到符合条件的位置，最后返回 `n - 1`；不能在第一次判断失败时就返回。
4. **变量保存的是数值而非下标。** 当前代码中的 `max_index` 和 `min_index` 实际保存最大值、最小值，更直观的命名可以是 `maxValue` 和 `suffixMin`，但整理版保留了你的原命名。
