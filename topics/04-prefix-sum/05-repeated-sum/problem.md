## 题意

给定一个长度为 `n` 的数组，把整个数组复制 `k` 份并依次拼接。复制后数组使用从 `0` 开始的下标，求其闭区间 `[l, r]` 的元素和。

不需要真的建立长度为 `n * k` 的新数组。新数组由完全相同的原数组周期性重复，可以利用一份原数组的前缀和计算任意长前缀。

## 原数组的前缀和

定义：

```cpp
prefix[i]
```

表示原数组前 `i` 个元素的和，并令：

```cpp
prefix[0] = 0;
```

输入原数组第 `i` 个元素时：

```cpp
prefix[i + 1] = prefix[i] + value;
```

因此：

- `prefix[1]` 表示原数组下标 `0` 这一个元素的和；
- `prefix[n]` 表示整个原数组的和。

前缀和数组以下标表示“元素数量”，所以它从 `0` 到 `n`；这与原数组从 `0` 到 `n - 1` 的元素下标含义不同。

## 重复数组前 `count` 个元素的和

定义函数：

```cpp
getPrefix(count)
```

表示重复数组中前 `count` 个元素的和。注意，`count` 是元素数量，不是最后一个元素的下标。

前 `count` 个元素可以分成两部分：

1. `count / n` 个完整的原数组；
2. 最后剩余的 `count % n` 个元素。

因此：

```cpp
long long getPrefix(long long count) {
    return (count / n) * prefix[n]
         + prefix[count % n];
}
```

这就是“先算完整部分，再算残余部分”。

## 从 0 下标区间换算成元素数量

题目要求的是从 `0` 开始的闭区间 `[l, r]`。

`getPrefix(r + 1)` 表示下标 `0...r` 的和，因为其中共有 `r + 1` 个元素；`getPrefix(l)` 表示下标 `0...l-1` 的和。因此：

```cpp
answer = getPrefix(r + 1) - getPrefix(l);
```

不能写成：

```cpp
getPrefix(r) - getPrefix(l - 1)
```

后者是把 `l`、`r` 当成从 `1` 开始的位置。特别是 `l == 0` 时还会调用 `getPrefix(-1)`，随后可能访问负数下标，产生未定义行为。

## 例子

原数组为：

```text
1 2 3
```

复制两份后：

```text
下标：0 1 2 3 4 5
数值：1 2 3 1 2 3
```

查询闭区间 `[1, 4]`，答案是：

```text
2 + 3 + 1 + 2 = 8
```

使用前缀函数：

```text
getPrefix(5) = 1 * 6 + prefix[2] = 9
getPrefix(1) = 0 * 6 + prefix[1] = 1
answer = 9 - 1 = 8
```

## 为什么 `k` 没有参与公式

`k` 决定复制后数组的合法总长度 `n * k`，但计算某个已经保证合法的前缀时，只需要知道周期长度 `n`、一个周期的总和以及剩余元素数量。因此，只要题目保证 `[l, r]` 位于复制后数组范围内，计算公式不需要直接使用 `k`。

## 类型选择

原数组长度较小时，`n` 可以使用 `int`。复制次数和复制后数组的下标可能很大，因此更稳妥的写法是：

```cpp
int n;
long long k, l, r;
```

`getPrefix` 的参数也必须是 `long long`，否则较大的 `r + 1` 在传入函数前可能发生溢出。前缀和、完整数组数量乘总和以及最终答案也使用 `long long`。

## 复杂度

- 时间复杂度：`O(n)`，只需读取并预处理一份原数组；
- 空间复杂度：`O(n)`，用于保存原数组前缀和。

## 主要易错点

1. 不要真的建立 `n * k` 个元素，只需预处理一份原数组。
2. `prefix[n]` 才是整个原数组之和，`prefix[n - 1]` 会漏掉最后一个元素。
3. `getPrefix(count)` 的参数表示元素数量，不是数组下标。
4. 从 `0` 开始的闭区间 `[l, r]` 应写成 `getPrefix(r + 1) - getPrefix(l)`。
5. `l == 0` 时不能计算 `getPrefix(l - 1)`，否则会出现负数取模和负下标。
6. `l`、`r` 和 `getPrefix` 的参数可能超过 `int` 范围，应使用 `long long`。
7. 原数组前缀和只能用 `0...n` 作为下标，不能直接用复制后数组的巨大位置访问 `prefix[l]` 或 `prefix[r]`。
