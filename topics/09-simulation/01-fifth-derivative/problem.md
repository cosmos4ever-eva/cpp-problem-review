## 题意

输入多项式的 `n` 个项，每项由系数 `a` 和次数 `b` 表示。求多项式的五阶导函数，合并次数相同的项，并按照次数从高到低输出最终的非零项；若五阶导函数为零，则输出 `0 0`。

## 五次求导公式

对于原多项式中的一项：

```text
a * x^b
```

连续求导五次后得到：

```text
a * b * (b - 1) * (b - 2) * (b - 3) * (b - 4) * x^(b - 5)
```

因此：

- 新系数是 `a * b * (b - 1) * (b - 2) * (b - 3) * (b - 4)`；
- 新次数是 `b - 5`；
- 当 `b < 5` 时，这一项五次求导后为 `0`，不需要加入结果。

最初把连乘写成了 `a * (a - 1) * ...`，相当于对系数做下降连乘。真正会在每次求导后减一的是指数 `b`，原系数 `a` 只乘一次。

## 用数组建立“次数到系数”的映射

令：

```text
f[k] = 五次求导后，x^k 的总系数
```

数组下标 `k` 表示指数，数组值 `f[k]` 表示对应系数。原来次数为 `b` 的项求导后，应累加到：

```cpp
f[b - 5]
```

这样从数组最大下标向 `0` 遍历，就能自然按照次数从高到低输出，不需要再对结果排序。

固定写成 `f[6]` 的前提是题目数据保证五次求导后的指数只会落在 `0...5`，也就是需要处理的原指数不超过 `10`。如果指数上界更大，就必须相应扩大数组，或改用按指数存储的映射容器，否则 `f[b - 5]` 会越界。

## 为什么必须先清零并使用 `+=`

可能有多个原始项在求导后得到相同次数，所以不能直接覆盖：

```cpp
f[b - 5] = coefficient;   // 会丢失之前的同次数项
```

应先把所有位置初始化为 `0`，再累加：

```cpp
long long f[6] = {};
f[b - 5] += coefficient;
```

例如 `2x^8` 和 `3x^8` 五次求导后的次数都为 `3`，它们的系数应共同累加到 `f[3]`。

## 如何判断最终结果为零

不能只根据“是否出现过 `b >= 5` 的项”判断结果非零，因为次数相同的项可能正负抵消。应先完成全部累加，再遍历 `f`：只要输出过一个非零系数，就说明结果非零；如果最终一个非零系数都没有，输出 `0 0`。

## 普通数组初始化

`int f[6]` 是 C 风格普通数组，没有 `.size()` 成员函数，因此 `f.size()` 会编译失败。使用 `memset` 清零时，第三个参数需要的是字节数，可以写：

```cpp
memset(f, 0, sizeof(f));
```

本题整理版直接写成：

```cpp
long long f[6] = {};
```

既能完成零初始化，也避免求导系数连乘时过早发生 `int` 溢出；表达式开头的 `1LL` 保证中间乘法使用 `long long`。

## 复杂度

- 时间复杂度：`O(n)`，每个原始项只处理一次，最后遍历定长结果数组。
- 空间复杂度：`O(n)`，输入使用两个长度为 `n` 的数组；结果数组是常数大小。若边读边处理，额外空间可以降为 `O(1)`。

## 主要易错点

1. 五次求导的下降连乘来自指数 `b`，不是系数 `a`。
2. 五次求导必须完整乘到 `(b - 4)`，不能只乘四个指数因子。
3. `f[k]` 的下标表示结果指数，值表示该指数对应的总系数。
4. 相同次数的项要使用 `+=` 合并，因此结果数组必须先清零。
5. 普通数组没有 `.size()`；`memset` 的长度参数使用 `sizeof(f)`。
6. 应根据累加后的最终数组判断零多项式，避免同次数项抵消后没有任何输出。
7. 系数包含多次乘法，使用 `long long` 并从 `1LL` 开始计算更安全。
8. 定长数组必须覆盖所有可能的结果指数；`f[6]` 只允许访问下标 `0...5`。
