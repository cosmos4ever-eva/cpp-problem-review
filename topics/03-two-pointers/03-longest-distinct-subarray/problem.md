## 题意

给定一个长度为 `n` 的整数数组，寻找其中最长的连续子数组，使子数组中的所有元素互不相同，输出该子数组的长度。

数据范围：`1 <= n <= 10^5`，`1 <= a[i] <= 10^9`。

## 核心思路

维护一个合法窗口 `[left, right]`，并用哈希表 `cnt` 记录窗口中每个数的出现次数。

每轮都将 `a[right]` 加入窗口。如果它的出现次数大于 `1`，说明窗口中产生了重复元素，就不断移动左端点，同时减少被移出元素的计数，直到 `a[right]` 在窗口中只出现一次。此时窗口重新合法，可以用 `right - left + 1` 更新最大长度。

## 滑动窗口框架

```cpp
for (int right = 0; right < n; ++right) {
    ++cnt[a[right]];

    while (cnt[a[right]] > 1) {
        --cnt[a[left]];
        ++left;
    }

    answer = max(answer, right - left + 1);
}
```

右指针在每一轮都固定右移一次，因此使用 `for` 循环最清晰；左指针只在窗口出现重复元素时移动。

## 复杂度

- 时间：平均 `O(n)`。左右指针都只会向右移动，每个元素至多进入和离开窗口各一次。
- 空间：`O(n)`。最坏情况下哈希表需要记录所有互不相同的元素。

## 主要易错点

1. **右指针每轮都要右移。** 这种移动规则适合写成 `for` 循环，避免某个分支没有移动 `right` 而形成死循环。
2. **先加入窗口，再判断是否重复。** 每轮先执行 `++cnt[a[right]]`，重复条件应写成 `cnt[a[right]] > 1`。
3. **不能只判断 `cnt[a[right]] != 0`。** 当前元素加入之前已经出现过，只能说明它即将造成重复；仍需先增加计数，再收缩窗口。
4. **哈希表以元素值为键。** `cnt[a[right]]` 表示查询数值 `a[right]` 在当前窗口中的出现次数。这里的 `a[right]` 是 `unordered_map` 的键，并不是普通计数数组的固定下标。
5. **窗口长度是 `right - left + 1`。** 此处左右端点都包含在窗口内，并且计算长度时 `right` 尚未自增。

## 对原始代码的整理

原始代码的算法已经正确。整理版主要加入快速输入设置、使用范围 `for` 循环读取数组，并将答案变量命名为 `maxLength`，算法本身没有改变。
