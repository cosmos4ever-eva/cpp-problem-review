## 题意

给定两个由互不相同的正整数组成、并且已经升序排列的集合 `S1` 和 `S2`，按升序输出差集 `S1 - S2`。如果差集为空，则不输出任何内容。要求使用双指针完成。

数据范围：`1 <= n, m <= 10^4`，集合元素不超过 `10^4`。

## 核心思路

分别使用指针 `i` 和 `j` 指向 `S1`、`S2` 当前还未处理的元素：

1. `S1[i] < S2[j]`：由于两个集合均已升序，`S1[i]` 不可能在 `S2` 后面出现，因此它属于差集，加入结果并移动 `i`。
2. `S1[i] == S2[j]`：该元素同时属于两个集合，不属于差集，两个指针一起移动。
3. `S1[i] > S2[j]`：`S2[j]` 不可能再匹配当前或后面的更小元素，只移动 `j`。

主循环结束后，如果 `S1` 还有剩余元素，说明 `S2` 已经扫描完，这些元素全部属于差集，需要单独加入结果。

## 双指针标准框架

```cpp
while (i < n && j < m) {
    if (first[i] < second[j]) {
        // 处理 first[i]
        ++i;
    } else if (first[i] == second[j]) {
        ++i;
        ++j;
    } else {
        ++j;
    }
}

while (i < n) {
    // 处理 first 中剩余的元素
    ++i;
}
```

具体移动哪一个指针由题目目标决定，但“双方都未结束时同步扫描，结束后处理剩余部分”是常见框架。

## 复杂度

- 时间：`O(n + m)`。两个指针都只向右移动。
- 空间：`O(n)`，用于保存最坏情况下包含整个 `S1` 的差集。

## 主要易错点

1. **结果数组需要动态追加。** 差集大小事先未知，应写 `vector<int> difference;`，再用 `push_back` 添加。不能写成 `vector<int> difference(n)`，因为这会预先创建 `n` 个值为 `0` 的元素。
2. **主循环的标准边界是 `while (i < n && j < m)`。** 只有两个指针都有效时才能比较 `first[i]` 和 `second[j]`。
3. **`S1` 的剩余元素必须单独处理。** 如果 `S2` 先结束，`S1` 后面的所有元素都不在 `S2` 中，应全部加入差集。
4. **差集为空时不输出。** 非空时才遍历输出，并控制空格只出现在两个数字之间。

## 对原始代码的整理

原始算法是正确的。整理版主要做了这些调整：

1. 删除未使用的 `MAXN`。
2. 使用更明确的变量名 `firstSet`、`secondSet` 和 `difference`。
3. 使用 `reserve(n)` 只预留最多 `n` 个结果的容量，但不预先创建元素。
4. 保留清晰的双指针主循环和 `S1` 剩余元素处理循环。
