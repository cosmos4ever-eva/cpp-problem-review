# 09 最大连续子序列和的最优方案

## 题意

给定一个整数序列，求最大连续子序列和，并输出对应连续区间的左右端点下标。

存在多个最大和区间时：

1. 优先选择左端点最小的区间；
2. 如果左端点仍相同，选择右端点最小的区间。

## 状态定义

定义：

```cpp
dp[i]
```

表示必须包含 `a[i]`、并且以 `a[i]` 结尾的最大连续子序列和。

同时定义：

```cpp
start[i]
```

表示取得 `dp[i]` 时，这段连续子序列的左端点。

由于 `dp[i]` 要求区间以 `a[i]` 结尾，所以它的右端点天然就是 `i`，不需要再建立一个右端点数组。

## 和的状态转移

处理 `a[i]` 时有两种选择：

1. 接在以 `a[i-1]` 结尾的区间后面；
2. 放弃前面的区间，从 `a[i]` 重新开始。

因此：

```cpp
dp[i] = max(dp[i-1] + a[i], a[i]);
```

## `start` 必须同步更新

`start[i]` 是当前 DP 状态的一部分，后续计算 `start[i+1]` 时可能继续使用它。因此每次计算 `dp[i]` 都必须同时确定 `start[i]`，不能只在 `dp[i]` 刷新全局最大和时才赋值。

如果保留前面的区间：

```cpp
start[i] = start[i-1];
```

如果从当前元素重新开始：

```cpp
start[i] = i;
```

对应代码是：

```cpp
if(dp[i-1] >= 0) start[i] = start[i-1];
else start[i] = i;
```

## 为什么条件应使用 `>= 0`

当 `dp[i-1] > 0` 时，接上前面的区间会使总和更大，显然应该沿用以前的起点。

当 `dp[i-1] < 0` 时，接上前面的区间会使总和变小，所以应该从 `i` 重新开始。

当 `dp[i-1] == 0` 时：

```text
dp[i-1] + a[i] == a[i]
```

两种方案的和相同，但接上前面的区间具有更小的左端点，符合题目的优先规则。因此整理版使用 `>= 0`。

例如：

```text
0 1
```

最大和为 `1`，区间 `[1,2]` 和 `[2,2]` 都能取得该最大和。题目要求优先输出左端点更小的 `[1,2]`。

## 选择全局最优区间

先求出所有 `dp[i]` 的最大值 `max_sum`，再按照右端点 `i` 从小到大检查：

```cpp
if(dp[i] == max_sum && start[i] < l){
    l = start[i];
    r = i;
}
```

这里只在左端点更小时更新。如果 `start[i] == l`，则保留之前的答案。由于 `i` 是从小到大遍历的，之前保存的右端点必然更小，所以已经自动满足第二层优先规则。

也就是说，不需要建立 `r[i]` 数组，只需要使用一个变量 `r` 保存当前选中的右端点。

## 初始化

连续子序列不能为空，所以第一个状态必须从第一个元素本身开始：

```cpp
dp[1] = a[1];
start[1] = 1;
int max_sum = a[1];
```

这样在数组全部为负数时，也能正确选择其中最大的单个元素，而不会错误选择和为 `0` 的空区间。

## 复杂度

- 时间复杂度：`O(n)`；
- 空间复杂度：`O(n)`。

## 主要易错点

1. `dp[i]` 表示以 `i` 结尾的最大连续子序列和，不是前 `i` 个元素中的全局最大和。
2. `start[i]` 必须和每个 `dp[i]` 同步计算，否则后续状态可能读取未初始化的起点。
3. 当 `dp[i-1] == 0` 时应继续前一区间，以保留更小的左端点，因此条件使用 `>= 0`。
4. `dp[i]` 对应区间的右端点就是 `i`，不需要建立右端点数组。
5. 按 `i` 从小到大遍历最终状态时，左端点相同便不更新，自然保留最小右端点。
