## 题意

给定一个整数序列，在保持元素原有顺序的前提下，选出最长的、公差为 `1` 的等差子序列。所选元素在原序列中的位置不必连续，输出该子序列的长度。

例如：

```text
1 4 2 3 7 4 5 6
```

可以依次选出：

```text
1 2 3 4 5 6
```

答案为 `6`。

## 基础动态规划

定义：

```cpp
dp[i]
```

表示必须选择 `a[i]`、并以 `a[i]` 结尾的最长公差为 `1` 的子序列长度。

每个元素单独选择时都能构成长度为 `1` 的子序列，因此：

```cpp
dp[i] = 1;
```

如果前面某个位置 `j` 满足：

```cpp
j < i && a[j] == a[i] - 1
```

那么可以把 `a[i]` 接到以 `a[j]` 结尾的子序列后面：

```cpp
dp[i] = max(dp[i], dp[j] + 1);
```

最终答案不一定以最后一个元素结尾，所以要取所有 `dp[i]` 的最大值，而不是直接输出 `dp[n]`。

基础写法需要为每个 `i` 枚举前面的所有 `j`，时间复杂度为 `O(n^2)`。当 `n` 达到 `100000` 时，比较次数可能达到约 50 亿，容易超出时间限制。

## 用哈希表减少搜索时间

基础 DP 的内层循环只是在寻找：

> 前面所有数值等于 `a[i] - 1` 的位置中，最大的 `dp[j]` 是多少？

因此可以把已经计算过的结果按“数值”记录下来。定义：

```cpp
best[x]
```

表示目前扫描过的位置中，以数值 `x` 结尾的最长合法子序列长度。

读到当前数字 `x` 时，它只能接在数值 `x - 1` 后面，所以不再枚举所有前驱位置，而是直接转移：

```cpp
int current_len = best[x - 1] + 1;
```

然后更新以 `x` 结尾的最优状态：

```cpp
best[x] = max(best[x], current_len);
```

这里使用 `max`，是因为数值 `x` 可能重复出现；`best[x]` 必须始终保留目前出现过的最长结果。

`unordered_map` 的 `operator[]` 在键不存在时会创建该键，并把对应的 `int` 值初始化为 `0`。因此第一次访问 `best[x - 1]` 时，得到 `0`，当前数字自己构成长度为 `1` 的子序列。

这种写法本质上仍然是动态规划，只是把“按位置保存状态”改成了“按结尾数值汇总状态”，并用哈希表快速取得转移来源。

因为题目只要求最长长度，不要求输出具体选择了哪些元素，所以不需要保存前驱子序列本身。对于每个已经出现过的数值，只保存“以它结尾的最长长度”就足够了。下一个数值 `x` 读取 `x - 1` 对应的最长长度，便能得到自己的长度，从而形成：

```text
前驱数值的最长长度 -> 当前数值的最长长度
```

这就是哈希表状态之间的迭代关系。如果题目还要求输出具体子序列，才需要额外记录前驱位置等信息来还原方案。

## `memset` 为什么不能把 `int` 数组置为 1

错误写法：

```cpp
int dp[MAXN];
memset(dp, 1, sizeof(dp));
```

`memset` 的第二个参数不是要赋给每个 `int` 元素的整数，而是要写入每个字节的字节值。执行后，每个字节都变成：

```text
00000001
```

在常见的 4 字节 `int` 环境中，一个元素的二进制表示会变成：

```text
00000001 00000001 00000001 00000001
```

即十六进制 `0x01010101`，十进制为 `16843009`，所以程序会输出一个很大的数。

如果要把每个整数初始化为 `1`，可以使用循环：

```cpp
for (int i = 1; i <= n; i++) {
    dp[i] = 1;
}
```

或者使用：

```cpp
fill(dp, dp + MAXN, 1);
```

`memset(dp, 0, sizeof(dp))` 通常可以用于把整型数组清零，因为全零字节能够表示整数 `0`；但不能由此推断它也能把整型数组正确地置为任意整数。

## 复杂度

- 基础双层循环 DP：时间复杂度 `O(n^2)`，空间复杂度 `O(n)`；
- 哈希表优化 DP：平均时间复杂度 `O(n)`，空间复杂度 `O(n)`。

## 主要易错点

1. `memset` 按字节填充，`memset(dp, 1, sizeof(dp))` 不会得到整数数组 `{1, 1, ...}`。
2. `dp[i]` 表示以当前位置结尾的答案，因此基础写法必须先初始化为 `1`。
3. 最长子序列可能在任意位置结束，不能只输出 `dp[n]`。
4. 两层循环的 `O(n^2)` 写法在 `n` 很大时会超时。
5. 哈希表中的 `best[x]` 以“数值”为键，不是以数组下标 `i` 为键。
6. 必须按照输入顺序扫描，不能先排序，否则会破坏子序列的相对顺序要求。
