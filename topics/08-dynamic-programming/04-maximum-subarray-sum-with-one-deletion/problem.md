## 题意

给定一个整数序列，可以删除 `0` 个或 `1` 个元素。删除后求新序列的最大非空连续子序列和。

删除一个元素后，它左右两侧原本相邻于该元素的部分可以连接起来。例如：

```text
1 -10 2
```

删除 `-10` 后得到 `1 2`，最大连续子序列和为 `3`。

## 为什么需要二维状态

普通最大连续子序列和只需要记录结束位置。这道题还要知道删除机会处于什么状态，所以增加第二个维度：

```cpp
dp[i][0]
dp[i][1]
```

- `dp[i][0]`：不删除元素，并以 `a[i]` 结尾的最大连续子序列和；
- `dp[i][1]`：处理到第 `i` 个位置时，允许删除至多一个元素这条路线能够得到的最大和。

第二维负责把“是否已经进入删除路线”保留下来，使下一位置能够根据这个条件继续转移。

## 不删除路线的转移

计算 `dp[i][0]` 时有两种选择：

1. 把 `a[i]` 接在前面的连续区间后面；
2. 丢掉前面的区间，从 `a[i]` 重新开始。

因此：

```cpp
dp[i][0] = max(dp[i-1][0] + a[i], a[i]);
```

## 删除路线的转移

删除路线也有两种来源。

### 删除发生在前面

如果删除机会已经在前面处理，那么当前 `a[i]` 需要保留并接入区间：

```cpp
dp[i-1][1] + a[i]
```

### 删除当前元素

如果选择删除 `a[i]`，就不能把它加入总和，直接继承前一个位置尚未删除的结果：

```cpp
dp[i-1][0]
```

因此：

```cpp
dp[i][1] = max(dp[i-1][1] + a[i], dp[i-1][0]);
```

例如处理 `1 -10 2` 中的 `-10` 时，可以通过 `dp[i-1][0]` 删除当前元素并保留前面的 `1`；下一轮再加上 `2`，得到答案 `3`。

## 为什么只依赖 `i-1`

本题要求的是连续子序列。没有删除当前元素时，`a[i]` 前面只能连接 `a[i-1]`；删除当前元素时，也只能把处理到 `i-1` 的结果暂时保留下来，等待下一位置连接。

因此只需从相邻状态转移，不能枚举任意 `j < i`。任意跳到更早的 `j` 会一次跳过多个元素，违反最多只能删除一个元素的限制。

## 初始化与非空限制

第一个位置没有前一个状态，必须单独初始化，然后让递推循环从 `i = 1` 开始：

```cpp
dp[0][0] = a[0];
dp[0][1] = a[0];
```

本题允许删除 `0` 个或 `1` 个元素，因此删除路线在开始时也可以暂时不删除，保留 `a[0]`。

更重要的是，连续子序列不能为空。若把状态初始化为 `0`，当所有元素都是负数时，程序可能错误地选择空序列。例如 `-5 -2 -7` 的答案应为 `-2`，而不是 `0`。

所以最终答案也从第一个元素开始：

```cpp
int max_sum = a[0];
```

## 最终答案

最大连续子序列可能在任意位置结束，也可能使用或不使用删除机会，因此要检查全部状态：

```cpp
for(int i = 0;i < n;i++){
    if(dp[i][0] > max_sum) max_sum = dp[i][0];
    if(dp[i][1] > max_sum) max_sum = dp[i][1];
}
```

## 复杂度

- 时间复杂度：`O(n)`；
- 空间复杂度：当前代码使用二维 `dp` 数组，为 `O(n)`。

每个状态只依赖前一个位置，将来可以把空间优化为 `O(1)`；当前版本保留完整数组，更方便观察状态变化。

## 主要易错点

1. 第二个维度负责记录删除状态：`0` 表示不走删除路线，`1` 表示允许删除至多一个元素的路线。
2. 写转移关系时要分别讨论“删除发生在前面”和“删除当前元素”两个来源。
3. 题目要求连续子序列，所以只能从 `i-1` 转移，不能枚举任意 `j < i`。
4. 第一个位置要单独初始化，循环从 `i = 1` 开始，避免访问 `dp[-1]`。
5. 连续子序列不能为空，数组又可能全部为负数，因此状态和最终答案不能初始化为 `0`，应从 `a[0]` 开始。
