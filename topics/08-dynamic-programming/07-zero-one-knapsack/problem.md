## 题意

有 `n` 件物品，第 `i` 件物品的重量为 `w[i]`、价值为 `c[i]`。每件物品最多选择一次，在总重量不超过背包容量 `v` 的前提下，求能够取得的最大总价值。

每件物品只有“选择一次”和“不选择”两种情况，因此称为 01 背包。

## 状态定义

定义：

```cpp
dp[i][j]
```

表示只考虑前 `i` 件物品，背包允许的总重量不超过 `j` 时，可以取得的最大价值。

- 第一维 `i` 表示可以考虑的物品范围；
- 第二维 `j` 表示背包的容量上限。

这里的 `j` 表示“不超过 `j`”，不要求选择的物品恰好装满容量。

## 为什么每件物品都要枚举容量

对于每个固定的 `i`，都要计算：

```text
dp[i][0], dp[i][1], ..., dp[i][v]
```

计算后面的物品时，选择物品可能产生各种剩余容量 `j-w[i]`，转移需要使用这些不同容量对应的旧答案。因此不能只计算最终的 `dp[i][v]`。

容量 `v` 本身也是要计算的合法状态，所以内层循环写成：

```cpp
for(int j = 0;j <= v;j++)
```

## 装不下当前物品

如果当前容量小于第 `i` 件物品的重量：

```cpp
w[i] > j
```

当前物品无法选择，只能继承不考虑它时的答案：

```cpp
dp[i][j] = dp[i-1][j];
```

## 能装下当前物品

如果 `w[i] <= j`，有两种选择。

### 不选择第 i 件物品

容量没有被消耗，答案为：

```cpp
dp[i-1][j]
```

### 选择第 i 件物品

选择它会得到 `c[i]` 的价值，并消耗 `w[i]` 的容量。剩余容量为 `j-w[i]`，剩余物品只能从前 `i-1` 件中选择：

```cpp
dp[i-1][j-w[i]] + c[i]
```

因此完整转移为：

```cpp
dp[i][j] = max(dp[i-1][j],
               dp[i-1][j-w[i]] + c[i]);
```

选择当前物品时从第 `i-1` 行转移，保证第 `i` 件物品不会被重复选择。

## 初始状态

第 `0` 行表示一件物品都没有考虑，此时无论容量是多少，最大价值都是 `0`：

```text
dp[0][j] = 0
```

程序通过下面的代码将整个 DP 数组初始化为 `0`：

```cpp
memset(dp,0,sizeof(dp));
```

## 下标统一

当前代码把物品数组和 DP 的物品维度都从 `1` 开始：

```cpp
for(int i = 1;i <= n;i++) cin >> w[i];
for(int i = 1;i <= n;i++) cin >> c[i];
```

所以计算第 `i` 行时可以直接访问 `w[i]` 和 `c[i]`。如果输入时把物品放在 `w[0...n-1]` 中，转移时就必须改用 `w[i-1]` 和 `c[i-1]`，不能混用两套下标。

## 最终答案

```cpp
dp[n][v]
```

表示考虑全部 `n` 件物品、容量上限为 `v` 时的最大价值，也就是题目答案。

## 复杂度

- 时间复杂度：`O(nv)`；
- 空间复杂度：`O(nv)`。

## 主要易错点

1. `dp[i][j]` 中的 `i` 表示前 `i` 件物品，`j` 表示背包允许的总重量上限。
2. 每个 `i` 都要枚举 `0...v` 的全部容量状态，不能只计算最大容量。
3. 装不下时只能继承上一行；装得下时比较选择与不选择两种方案。
4. 选择第 `i` 件物品时从 `dp[i-1]` 转移，避免重复选择。
5. 数组从 `0` 还是从 `1` 开始必须前后一致。
6. `max` 对应的标准头文件是 `<algorithm>`。
