# 08 疯狂下楼梯

## 题意

楼梯位置编号为 `0...n`，开始时位于第 `0` 号台阶。每一步可以跳 `1...k` 级，但不能落到有水的台阶上。求恰好到达第 `n` 号台阶的方案数，并对 `1000000007` 取余。

## 状态定义

定义：

```cpp
dp[i]
```

表示从第 `0` 号台阶出发，恰好到达第 `i` 号台阶的方案数。

## 转移关系

如果最后一步跳了 `j` 级，那么跳跃前位于第 `i-j` 号台阶。最后一步可能跳 `1...k` 级，所以：

```cpp
dp[i] = dp[i-1] + dp[i-2] + ... + dp[i-k]
```

只累加下标不小于 `0` 的位置，代码写成：

```cpp
for(int j = 1;j <= k;j++){
    if(j > i) break;
    dp[i] = (dp[i] + dp[i-j]) % (int)(1e9 + 7);
}
```

## 为什么 `dp[0] = 1`

第 `0` 号台阶是起点。还没有进行任何跳跃时，已经有一种位于起点的初始方案，因此：

```cpp
dp[0] = 1;
```

这个 `1` 会为后面的第一步提供方案来源。例如 `i = 2` 且允许一次跳 `2` 级时，`dp[2]` 应包含 `dp[0]`，代表：

```text
0 -> 2
```

如果错误地设置 `dp[1] = 1`，相当于默认所有路线必须先经过第 `1` 号台阶，会漏掉从起点直接跨到后面台阶的路线。

## 为什么 `j` 可以等于 `i`

当 `j == i` 时：

```cpp
i-j == 0
```

这表示从起点直接跳到第 `i` 号台阶，是合法方案。只有 `j > i` 时才会得到负下标，因此循环中的停止条件是：

```cpp
if(j > i) break;
```

不能写成 `j >= i`。

## 有水台阶

`a[i]` 表示第 `i` 号台阶能否落脚：

```cpp
a[i] == true   // 可以落脚
a[i] == false  // 有水，不能落脚
```

如果当前台阶有水，就不存在到达该位置的合法方案：

```cpp
dp[i] = 0;
```

由于后面的状态只会累加已有的 `dp`，这个位置自然不会成为后续路线的来源。

## 为什么其余状态初始化为 0

计算一个普通位置时，程序在内层循环中反复执行：

```cpp
dp[i] = dp[i] + dp[i-j];
```

因此累加前必须让 `dp[i]` 从 `0` 开始。程序先把整个数组初始化为 `0`，再单独设置起点：

```cpp
memset(dp,0,sizeof(dp));
dp[0] = 1;
```

## 为什么要在循环中取余

方案数可能在递推到终点前就已经非常大。如果只在最后输出时取余，中间的 `int` 可能先发生溢出，之后无法恢复正确结果。

所以每一次累加都要取余：

```cpp
dp[i] = (dp[i] + dp[i-j]) % (int)(1e9 + 7);
```

## 复杂度

- 时间复杂度：`O(nk)`；
- 空间复杂度：`O(n)`。

## 主要易错点

1. 起点是一种初始状态，要设置 `dp[0] = 1`。
2. `j == i` 表示从起点直接跳到当前位置，不能提前排除。
3. 除 `dp[0]` 外，其余位置在累加前都应初始化为 `0`。
4. 有水的台阶对应的方案数必须为 `0`。
5. 取余必须发生在每次累加过程中，不能只在最终输出时进行。
