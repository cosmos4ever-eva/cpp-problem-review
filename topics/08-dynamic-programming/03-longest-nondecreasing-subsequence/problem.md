# 03 最长上升子序列

## 题意

给定一个整数序列，选择其中若干个元素组成子序列。被选择的元素不要求在原序列中连续，但必须保持原来的先后顺序。求元素非递减的最长子序列长度。

题目标题使用“最长上升子序列”，但题意要求的是“非递减”，因此相邻元素可以相等，代码中的比较条件应使用 `<=`。

## 状态定义

定义：

```cpp
dp[i]
```

表示**选择 `a[i]`，并且以 `a[i]` 结尾的最长不下降子序列长度**。

“以 `a[i]` 结尾”保证了状态能够继续转移：如果前面某个位置 `j` 满足 `a[j] <= a[i]`，就可以把 `a[i]` 接到以 `a[j]` 结尾的子序列后面。

## 初始化

即使前面没有任何数字能够接到 `a[i]` 前面，`a[i]` 自己也能构成一个长度为 `1` 的子序列。因此每个位置都必须初始化为：

```cpp
dp[i] = 1;
```

不能只初始化 `dp[0]`，也不能让后面的状态保持默认值 `0`。如果某个位置没有合法前驱，它的正确答案仍然是 `1`；错误的 `0` 还可能继续影响后续状态。

## 状态转移

对于当前结束位置 `i`，枚举前面所有位置：

```cpp
for(int j = 0;j < i;j++)
```

如果：

```cpp
a[j] <= a[i]
```

那么可以在以 `a[j]` 结尾的最长不下降子序列后面加入 `a[i]`，得到长度：

```cpp
dp[j] + 1
```

前面可能有多个位置满足要求，所以选择其中最长的结果：

```cpp
if(a[j] <= a[i]){
    dp[i] = max(dp[i], dp[j] + 1);
}
```

可以把完整转移理解为：

```text
dp[i] = 1
dp[i] = max(dp[i], dp[j] + 1)
其中 j < i 且 a[j] <= a[i]
```

## 最终答案

`dp[i]` 只表示以位置 `i` 结尾的答案，而最长不下降子序列可能在任意位置结束，所以还要维护所有 `dp[i]` 的最大值：

```cpp
if(dp[i] > max_dp) max_dp = dp[i];
```

## 动态规划的核心步骤

这道题体现了两个通用步骤：

1. 根据题意定义 `dp[i]`，并明确“必须以当前位置结尾”这一限制；
2. 寻找 `dp[i]` 与前面状态 `dp[j]` 的递推关系，再根据状态本身的最小合法答案确定初始化值。

这里使用的是状态递推，而不是递归函数调用。

## `<=` 与 `<` 的区别

- 非递减子序列允许相等数字相邻，使用 `a[j] <= a[i]`；
- 严格递增子序列不允许相等，使用 `a[j] < a[i]`。

例如 `1 2 2 4` 是合法的非递减子序列，但不是严格递增子序列。

## 复杂度

- 时间复杂度：`O(n^2)`，因为每个 `i` 都要枚举前面的所有 `j`；
- 空间复杂度：`O(n)`，用于保存 `dp` 数组。

## 主要易错点

1. `dp[i]` 表示选择 `a[i]`、并以 `a[i]` 结尾的最长不下降子序列长度，不是前 `i + 1` 个位置中的全局最长长度。
2. 每个位置至少可以选择自己，所以每一轮都必须令 `dp[i] = 1`，不能只初始化 `dp[0]`。
3. 枚举前驱时必须满足 `j < i`，以保证子序列保持原来的先后顺序。
4. 本题允许相等元素，所以连接条件为 `a[j] <= a[i]`。
5. 最长子序列可能在任意位置结束，最终还要取所有 `dp[i]` 的最大值。
6. `std::max` 正式定义在 `<algorithm>` 中，整理版只补充了这个必要头文件。
