## 题意

给定两个只包含小写字母的字符串，求它们的最长公共子序列长度。子序列中的字符不要求连续，但必须保持各自在原字符串中的先后顺序。

## 状态定义

定义：

```cpp
dp[i][j]
```

表示 `s1` 的前 `i` 个字符与 `s2` 的前 `j` 个字符的最长公共子序列长度。

这里需要二维状态，因为两个字符串的处理进度互相独立：

- `i` 决定 `s1` 取多长的前缀；
- `j` 决定 `s2` 取多长的前缀。

对每一个固定的 `i`，都必须枚举 `s2` 的全部前缀，所以使用两层循环填满整张 DP 表。

## 下标为什么相差一位

`dp` 下标表示前缀中包含的字符数量，而字符串下标从 `0` 开始。前 `i` 个字符中的最后一个字符是：

```cpp
s1[i-1]
```

同理，`s2` 当前前缀的最后一个字符是：

```cpp
s2[j-1]
```

因此 DP 循环从 `1` 开始，并且必须计算到字符串长度本身：

```cpp
for(int i = 1;i <= s1.size();i++)
for(int j = 1;j <= s2.size();j++)
```

如果写成 `< s1.size()`，最后输出的 `dp[s1.size()][s2.size()]` 就从未被计算。

## 边界初始化

第 `0` 行和第 `0` 列表示其中一个字符串为空：

```text
dp[0][j] = 0
dp[i][0] = 0
```

空字符串与任何字符串都没有公共字符，所以答案为 `0`。当前 `dp` 是局部数组，通过 `{0}` 显式完成全部初始化：

```cpp
int dp[MAXN][101] = {0};
```

## 两个末尾字符相等

如果：

```cpp
s1[i-1] == s2[j-1]
```

当前两个字符可以作为同一个公共字符配对。先求去掉它们后的两个前缀的答案，再加入当前字符：

```cpp
dp[i][j] = dp[i-1][j-1] + 1;
```

这里从左上角状态转移。

## 两个末尾字符不相等

如果两个末尾字符不相等，它们不能互相配对，因此最终公共子序列中至少有一个末尾字符没有被选择：

```cpp
dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
```

- `dp[i-1][j]`：不再考虑 `s1` 当前的末尾字符；
- `dp[i][j-1]`：不再考虑 `s2` 当前的末尾字符。

保留在另一个前缀中的末尾字符只是仍然可以选择，并不是必须选择。因此，如果两个末尾字符都不选，这种方案也同时包含在上边和左边的子问题中，不需要额外比较 `dp[i-1][j-1]`。

## 为什么取最大值不会漏掉后面的最优解

这里不是贪心地永久选择一条具体字符路径。每个格子只保存对应两段前缀能够达到的最大长度，而上边和左边的状态仍然完整保留在 DP 表中。

对于当前固定的两个前缀，字符不相等时的全部合法公共子序列，必然属于“不使用第一个字符串末尾字符”或“不使用第二个字符串末尾字符”中的至少一种。因此二者的最大值就是当前状态的最优长度，没有第三种更优来源。

题目只要求长度，所以不需要在状态中保存具体选择了哪些字符。如果以后要求输出一个具体的最长公共子序列，可以从右下角根据状态来源回溯。

## 填表顺序

当前状态可能依赖：

```text
左上角 dp[i-1][j-1]
上方   dp[i-1][j]
左方   dp[i][j-1]
```

因此按照从上到下、每行从左到右的顺序填表，可以保证使用这些状态时它们都已经计算完成。

## 复杂度

设两个字符串长度分别为 `n` 和 `m`：

- 时间复杂度：`O(nm)`；
- 空间复杂度：`O(nm)`。

## 主要易错点

1. `dp[i][j]` 表示两段前缀的最优答案，不要求一定选择这两段前缀的末尾字符。
2. `i` 和 `j` 是两个字符串独立的处理进度，需要两层循环枚举完整二维状态。
3. DP 下标表示前缀长度，字符串下标从 `0` 开始，因此比较 `s1[i-1]` 和 `s2[j-1]`。
4. 循环必须使用 `<= length`，否则最终输出位置没有被计算。
5. 末尾字符相等时从左上角加一；不相等时取上方与左方的最大值。
6. 使用 `std::max` 应包含 `<algorithm>`。整理版只补充了这个必要头文件。
