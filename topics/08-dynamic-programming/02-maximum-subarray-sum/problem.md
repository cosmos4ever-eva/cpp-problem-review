## 题意

给定一个整数序列，求其中非空连续子序列的最大和。序列中可以出现负数。

## 状态定义

定义：

```cpp
dp[i]
```

表示**必须包含 `a[i]`，并且以 `a[i]` 结尾**的最大连续子序列和。

这里不能把它理解为“前 `i + 1` 个元素中的最大连续子序列和”。前面任意位置结束的最大区间不一定能直接与 `a[i+1]` 相连，而以 `a[i]` 结尾的区间一定可以接上 `a[i+1]`，从而保证区间连续。

## 状态转移

计算 `dp[i]` 时只有两种选择。

### 接在前一个区间后面

`dp[i-1]` 必须以 `a[i-1]` 结尾，所以接上 `a[i]` 后仍是连续区间：

```cpp
dp[i-1] + a[i]
```

### 从当前位置重新开始

如果前一个区间的和为负数，接上它只会使结果变小，此时直接让连续子序列从 `a[i]` 开始：

```cpp
a[i]
```

两种选择取较大值，因此递推式为：

```cpp
dp[i] = max(a[i], dp[i-1] + a[i]);
```

这里是根据前一个状态计算后一个状态的**递推**，代码中并没有函数调用自身，所以不是递归。

## 初始化

第一个位置前面没有其他元素，因此：

```cpp
dp[0] = a[0];
```

数组可能全部由负数组成，所以最大值也必须从第一个元素开始：

```cpp
max_dp = a[0];
```

如果初始化为 `0`，例如输入 `-5 -2 -7` 时就会错误输出 `0`，相当于选择了题目不允许的空区间；正确答案应是 `-2`。

你的代码在读入第一个元素时完成了这两个初始化：

```cpp
if(i == 0) {
    dp[i] = a[i];
    max_dp = a[i];
}
```

## 最终答案

`dp[i]` 只表示必须以第 `i` 个元素结尾的答案。整个序列的最大连续子序列可能在任意位置结束，因此每次都要更新全局最大值：

```cpp
if(dp[i] > max_dp) max_dp = dp[i];
```

最终输出 `max_dp`。

## 复杂度

- 时间复杂度：`O(n)`；
- 空间复杂度：当前代码使用 `dp` 数组，为 `O(n)`。

因为 `dp[i]` 只依赖 `dp[i-1]`，以后还可以使用一个变量保存前一个状态，把额外空间优化到 `O(1)`；当前版本保留完整数组，更便于学习状态含义。

## 主要易错点

1. `dp[i]` 必须定义为“以 `a[i]` 结尾”的最大连续子序列和，这样才能保证与下一个元素相连后仍然连续。
2. 转移时比较“连接前一个区间”和“从当前元素重新开始”：`dp[i] = max(a[i], dp[i-1] + a[i])`。
3. 元素可以为负数，`dp[0]` 和 `max_dp` 都要初始化为 `a[0]`，不能初始化为 `0`。
4. `dp[i]` 不是整个数组的最终答案，还要用 `max_dp` 记录所有结束位置中的最大值。
5. `std::max` 正式定义在 `<algorithm>` 中，整理版只补充了这个必要头文件，没有改变你的程序结构。
