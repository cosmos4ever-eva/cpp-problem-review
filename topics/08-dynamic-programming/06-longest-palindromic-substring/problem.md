# 06 最长回文子串

- 状态：AI 辅助完成
- 建议复习：2026-09-12

## 题意

给定一个只包含小写字母的字符串，求其中最长回文子串的长度。子串必须连续；回文串从左向右读和从右向左读完全相同。

## 状态定义

定义：

```cpp
dp[i][j]
```

表示连续子串 `s[i...j]` 是否为回文串：

- `true` 表示是回文串；
- `false` 表示不是回文串。

这道题的状态描述的是一段区间，而不是只处理到某一个位置，因此属于区间动态规划。

## 转移关系

对于长度至少为 `3` 的子串 `s[i...j]`，它成为回文串需要同时满足：

1. 最左字符与最右字符相等，即 `s[i] == s[j]`；
2. 去掉两端后的内部子串 `s[i+1...j-1]` 是回文串。

因此判断条件是：

```cpp
s[i] == s[j] && dp[i+1][j-1]
```

当前代码用 `len` 表示区间长度，所以右端点为：

```cpp
j = i + len - 1;
```

代入后，内部区间就是：

```cpp
dp[i+1][i+len-2]
```

## 边界初始化

### 长度为 1

任何单独的字符都是回文串：

```cpp
dp[i][i] = true;
```

所以初始最长长度为 `1`。

### 长度为 2

两个相邻字符相等时，这两个字符组成回文串：

```cpp
if(s[i] == s[i+1]){
    dp[i][i+1] = true;
    max_len = 2;
}
```

访问 `s[i+1]` 前必须保证它存在，因此循环上界应为：

```cpp
i < s.size() - 1
```

不能把这个判断放在遍历全部字符的长度为 `1` 初始化循环里，否则最后一轮会访问 `s[s.size()]`，造成越界。

## 为什么按照长度递推

`dp[i][j]` 依赖内部的 `dp[i+1][j-1]`，也就是长度少 `2` 的区间。为了保证使用时内部状态已经算好，计算顺序必须是：

```text
长度 1 -> 长度 2 -> 长度 3 -> ... -> 整个字符串长度
```

因此外层枚举长度，内层枚举当前长度下所有可能的左端点。

## 为什么要初始化整个数组

`dp` 是 `main` 中的局部数组，不会自动全部变成 `false`。程序只会把确认是回文串的位置改为 `true`，其他位置必须保持 `false`，所以应写成：

```cpp
bool dp[MAXN][MAXN] = {false};
```

否则读取尚未赋值的 `dp[i+1][j-1]` 时会得到不确定的值。

## 复杂度

- 时间复杂度：`O(n^2)`；
- 空间复杂度：`O(n^2)`。

## 主要易错点

1. `dp[i][j]` 表示的是连续区间 `s[i...j]` 是否为回文串。
2. 长区间依赖短区间，所以必须按照区间长度从小到大递推。
3. 长度为 `1` 和长度为 `2` 的区间要分别初始化。
4. 局部 `bool` 数组要显式初始化为 `false`。
5. 判断相邻字符时，循环只能进行到倒数第二个字符，避免 `s[i+1]` 越界。
6. 长度为 `len`、左端点为 `i` 时，右端点是 `i + len - 1`，内部区间右端点是 `i + len - 2`。
