## 题意

数塔第 `1` 行有 `1` 个数，第 `2` 行有 `2` 个数，依此类推。每个位置只能走到下一行的左下方或右下方，求从塔顶走到塔底的最大路径和。

## 动态规划状态

定义：

```cpp
dp[i][j]
```

表示从第 `i` 行第 `j` 个位置出发，一直走到塔底能够取得的最大路径和。

## 初始化

最后一行已经位于塔底，从其中任意位置出发的最大路径和就是这个位置自身：

```cpp
for(int i = 1;i <= n;i ++){
    dp[n][i] = a[n][i];
}
```

## 状态转移

从 `(i,j)` 出发，下一步只有两个选择：

- 左下方 `(i+1,j)`；
- 右下方 `(i+1,j+1)`。

应选择两条后续路径中较大的一条，再加上当前位置的数字：

```cpp
dp[i][j] = max(dp[i+1][j],dp[i+1][j+1]) + a[i][j];
```

这条语句的逻辑是：

```text
当前位置的最大路径和
= 当前数字
+ max(从左下方出发的最大路径和, 从右下方出发的最大路径和)
```

## 为什么要从下往上计算

计算 `dp[i][j]` 之前，必须先知道下一行的 `dp[i+1][j]` 和 `dp[i+1][j+1]`。因此完成最后一行的初始化后，外层循环必须从倒数第二行开始向上计算：

```cpp
for(int i = n-1;i >= 1;i--){
    for(int j = 1;j <= i;j ++){
        dp[i][j] = max(dp[i+1][j],dp[i+1][j+1]) + a[i][j];
    }
}
```

最后，塔顶状态就是答案：

```cpp
dp[1][1]
```

## 另一种写法：记忆化搜索

[memoized.cpp](memoized.cpp) 使用自顶向下的递归。函数：

```cpp
F(i, j, n)
```

表示的状态与 `dp[i][j]` 完全相同，也是从 `(i,j)` 到塔底的最大路径和。

- 当 `i == n` 时已经到达最后一行，直接返回 `a[i][j]`；
- 如果 `memo[i][j] != -1`，说明这个状态已经计算过，直接返回缓存；
- 否则递归计算左下方和右下方的答案，取较大值并保存到 `memo[i][j]`。

记忆化搜索和自底向上动态规划的核心转移关系相同，区别只在计算顺序：

- 记忆化搜索从塔顶开始，递归到需要的状态，并把结果缓存起来；
- 递推写法从塔底开始，按照依赖关系逐行填表。

## 复杂度

数塔共有 `1 + 2 + ... + n` 个状态，因此两种写法都是：

- 时间复杂度：`O(n^2)`；
- 空间复杂度：`O(n^2)`。

记忆化搜索还会使用 `O(n)` 的递归调用栈。

## 主要易错点

1. `dp[i][j]` 的含义要先确定清楚：它表示从当前位置到塔底的最大路径和。
2. 最后一行必须先初始化为自身的值。
3. 当前行依赖下一行，所以外层循环必须写成 `for(int i = n-1;i >= 1;i--)`，从下往上计算。
4. 转移时不要漏掉当前位置：`dp[i][j] = max(dp[i+1][j],dp[i+1][j+1]) + a[i][j]`。
5. 记忆化搜索必须先检查缓存，否则同一个状态会被重复计算。
