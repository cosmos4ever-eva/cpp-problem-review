# 02 旋转数组的中位数

- 总题号：008
- 日期：2026-09-06
- 类型：排序、旋转有序数组、二分查找
- 状态：AI 辅助完成
- 建议复习：2026-09-07
- 原题：[Sunnywhy](https://sunnywhy.com/camp/3415/model/3591?itemId=3042)

## 题意

给定一个由严格递增序列形成的旋转数组，使用二分法找到原序列的中位数。数组长度为奇数时取中间元素，长度为偶数时取两个中间元素的平均值，结果保留一位小数。

## 核心思路

旋转不会改变元素的大小次序，只是把原序列从某个位置切开。先用二分查找找到最小值的下标 `minIndex`，它就是原严格递增序列在旋转数组中的起点；然后从这个起点偏移到中间位置。

### 二分判断折点方向

如果数组没有旋转，那么 `a[0] < a[n - 1]`，最小值下标直接是 `0`。

否则将 `a[mid]` 与最后一个元素 `a[n - 1]` 比较：

- `a[mid] > a[n - 1]`：`mid` 位于左侧较大的递增段，折点一定在右侧，令 `l = mid + 1`。
- `a[mid] <= a[n - 1]`：`mid` 位于右侧较小的递增段，折点在左侧；如果 `a[mid] < a[mid - 1]`，那么 `mid` 本身就是折点，否则令 `r = mid - 1`。

检查 `a[mid - 1]` 前必须保证 `mid > 0`，否则会越界。

### 中位数下标

找到原序列起点 `minIndex` 后，通过取模映射回旋转数组：

```cpp
// n 为奇数
int mid = (minIndex + n / 2) % n;

// n 为偶数
int mid1 = (minIndex + n / 2 - 1) % n;
int mid2 = (minIndex + n / 2) % n;
```

## 复杂度

- 时间：`O(log n)`，二分查找折点。
- 额外空间：`O(1)`；保存输入数组需要 `O(n)` 空间。

## 主要易错点

1. **输出需要浮点数。** 偶数长度时应先把两个中间元素转换为 `double`，再相加并除以 `2`。
2. **判断折点在哪一侧。** `a[mid] > a[n - 1]` 时向右查找，否则向左查找。
3. **不能访问 `a[-1]`。** 判断 `a[mid] < a[mid - 1]` 之前必须保证 `mid > 0`。
4. **未旋转也是合法情况。** 此时最小值下标为 `0`。
5. **中位数下标需要以最小值位置为起点。** 加上有序序列中的中间偏移后，再对 `n` 取模。

## 对原始代码的整理

整理版保留原始代码的整体结构、二分判断方法、中位数下标公式和输出方式，只做必要修改：

1. 删除 `findMin` 外层重复执行相同二分过程的 `for` 循环。
2. 增加未旋转数组的判断，并在访问 `a[mid - 1]` 前检查 `mid > 0`。
3. 使用 `const vector<int>&` 传递数组，避免复制。
4. 将主函数中的变量 `min` 改为 `minIndex`，明确它保存的是最小值下标，也避免与 `std::min` 重名。
