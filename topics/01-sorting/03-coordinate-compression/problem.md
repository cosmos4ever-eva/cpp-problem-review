## 题意

给定一个整数数组，将不同的数按照从小到大的顺序重新编号为 `0,1,2,...`，再按照原数组的顺序输出每个元素对应的新编号。

例如：

```text
原数组：2 999999999 3 3 999999999
大小关系：2 < 3 < 999999999
新编号：0 < 1 < 2
结果：0 2 1 1 2
```

离散化保留元素之间的大小关系和相等关系，但把跨度很大的数值压缩到一段连续的小编号中。

## 核心步骤

### 1. 复制原数组

```cpp
vector<int> b = a;
```

后面需要对 `a` 排序，但最终输出必须保持原输入顺序。因此用 `b` 保存原数组，使用 `a` 生成离散化所需的有序不同值。

`vector` 是支持复制的标准库容器，复制后修改 `a` 不会影响 `b`。C 风格普通数组不能使用赋值号进行整体复制。

### 2. 排序并去重

```cpp
sort(a.begin(),a.end());
a.erase(unique(a.begin(),a.end()),a.end());
```

排序后，相同元素会相邻。`unique` 把每种数值的第一个副本保留在前面的有效区间，并返回这个有效区间的新结尾，但不会真正修改 `vector` 的长度。

`erase` 再删除新结尾到原结尾之间的元素，最终让 `a` 只保留从小到大的不同数值。

以上面的数组为例：

```text
排序后：2 3 3 999999999 999999999
去重后：2 3 999999999
```

### 3. 建立原值到编号的映射

```cpp
unordered_map<int,int> rank;
```

映射关系为：

```text
原数值 -> 离散编号
```

代码按照去重数组的升序依次生成编号：

```cpp
rank[a[0]] = 0;
for(int i = 1;i < a.size();i++){
    rank[a[i]] = rank[a[i-1]] + 1;
}
```

这里的原数值是哈希表的“键”，不是普通数组的物理下标。因此即使原值非常大或包含负数，也能直接保存。

### 4. 按原顺序查询

```cpp
for(int i = 0;i < n;i++){
    cout << rank[b[i]];
}
```

遍历保存原顺序的 `b`，通过哈希表查出每个数对应的离散编号。

## 为什么建立哈希映射

如果对原数组中的每个元素都从头遍历去重数组寻找位置，最坏情况下需要 `O(n^2)` 时间。

当前代码只遍历有序去重数组一次来建立哈希表，之后每个原值平均可以在 `O(1)` 时间内查到编号。整体复杂度主要由排序决定。

除了哈希表，也可以对每个原值使用 `lower_bound` 在有序去重数组中查询，单次复杂度是 `O(log n)`。本题保留你使用哈希映射的实现。

## 复杂度

- 复制数组：`O(n)`；
- 排序：`O(n log n)`；
- 去重和建立映射：`O(n)`；
- 查询输出：平均 `O(n)`。

总时间复杂度为 `O(n log n)`，额外空间复杂度为 `O(n)`。

## 主要易错点

1. 排序前要复制原数组，否则会丢失题目要求的原始输出顺序。
2. `unique` 不会真正删除元素，必须将它返回的新结尾传给 `erase`。
3. 不要为每个原值线性扫描去重数组寻找排名，否则复杂度可能达到 `O(n^2)`。
4. 哈希表保存的是“原数值到编号”的映射，原数值是键，不是物理下标。
5. `vector` 可以整体复制，普通数组不能直接使用赋值号复制。
