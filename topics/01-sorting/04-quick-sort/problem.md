## 题意

输入 `n` 个正整数，使用快速排序将它们按从小到大的顺序排列。输出一行，整数之间用一个空格分隔，行末不能有多余空格。每个输入整数不超过 `1000`。

## 核心思路

当前函数负责排序闭区间 `[l,r]`：

1. 当区间中不足两个元素时直接返回。
2. 保存中间位置的值作为基准值 `pivot`。
3. 左指针从 `l-1` 出发，寻找第一个大于等于 `pivot` 的数。
4. 右指针从 `r+1` 出发，寻找第一个小于等于 `pivot` 的数。
5. 若两指针尚未交叉，交换这两个放错一侧的数。
6. 指针交叉后，递归处理 `[l,j]` 与 `[j+1,r]`。

这是一种 Hoare 风格的划分方式。一次划分结束后，不要求 `pivot` 恰好落在最终位置，只保证分界线两侧满足后续递归所需的大小关系。

## 为什么数组要传引用

函数签名是：

```cpp
void quicksort(vector<int>& a, int l, int r)
```

`vector<int>& a` 中的 `&` 表示引用。函数内部交换的就是 `main` 中原来的数组元素。

如果写成：

```cpp
void quicksort(vector<int> a, int l, int r)
```

每次递归都会复制一个新的 `vector`，函数中虽然能完成交换，但退出后外面的原数组不会得到这些修改，而且复制还会额外消耗时间和空间。

## 为什么比较固定的 `pivot`

先执行：

```cpp
int pivot = a[l + (r - l) / 2];
```

这里保存的是中间位置元素在本轮划分开始时的数值。后续必须与固定的 `pivot` 比较：

```cpp
do i++; while (a[i] < pivot);
do j--; while (a[j] > pivot);
```

不能反复与 `a[mid]` 比较。划分过程中会交换元素，中间下标 `mid` 上保存的值也可能被换走；如果比较标准随交换发生变化，当前划分就失去了固定基准，可能得到错误分区甚至无法正常结束。

## 为什么使用 `do...while`

初始位置是：

```cpp
int i = l - 1;
int j = r + 1;
```

它们暂时位于区间外，所以必须先移动一次，再访问数组元素：

```cpp
do i++; while (a[i] < pivot);
do j--; while (a[j] > pivot);
```

`do...while` 还保证每轮寻找都会让指针至少移动一次。即使刚交换的两个元素都等于 `pivot`，下一轮也不会停在原来的同一对位置无限交换。

因为 `pivot` 来自当前区间，所以左右扫描一定能在越过数组边界前遇到停止位置。

## 递归边界

当 `i >= j` 时，当前划分结束，使用 `j` 作为分界：

```cpp
quicksort(a, l, j);
quicksort(a, j + 1, r);
```

这一组递归区间必须与当前 Hoare 划分模板配套，不能随意改成围绕 `i` 或 `mid` 切分。

终止条件为：

```cpp
if (l >= r) return;
```

`l == r` 表示区间只有一个元素，已经天然有序；`l > r` 表示空区间。二者都不应继续划分。

## 输出格式

为了避免行末多余空格，在输出当前元素之前判断它是否为第一个元素：

```cpp
if (i != 0) cout << " ";
cout << a[i];
```

## 复杂度

- 平均时间复杂度：`O(n log n)`。
- 最坏时间复杂度：`O(n^2)`。
- 平均递归栈空间：`O(log n)`；最坏为 `O(n)`。

## 主要易错点

1. `vector` 必须使用引用传递 `vector<int>& a`，否则函数修改的是副本，主函数中的原数组不会改变。
2. 应先保存固定的基准值 `pivot`，后续与 `pivot` 比较；不能反复与可能在交换中变化的 `a[mid]` 比较。
3. `i=l-1、j=r+1` 与 `do...while` 是配套写法，必须先移动再访问数组。
4. `do...while` 保证指针每轮至少移动一次，避免相等元素使扫描停在原位置并反复交换。
5. 当前划分结束后应递归 `[l,j]` 和 `[j+1,r]`，递归边界必须与 Hoare 划分方式配套。
6. 终止条件是 `l>=r`，同时覆盖单元素区间和空区间。
7. `swap` 应显式包含 `<algorithm>` 或 `<utility>`，不要依赖其他头文件间接提供声明。
8. 输出空格应放在非首元素之前，避免行末出现多余空格。

## 调试方法

1. 先测试单元素、两个逆序元素、全部相等、已经升序、已经降序五组数据。
2. 每轮划分打印 `l、r、pivot、i、j` 以及交换后的数组，确认指针严格向中间推进。
3. 在每次递归前打印两个新区间，确认它们比原区间更小；若重复出现同一个区间，立即检查 `j` 和递归端点。
4. 把中间位置元素与其他元素交换的样例单独打印，确认后续比较仍使用保存的 `pivot`，而不是变化后的 `a[mid]`。
5. 若函数内排序正确但 `main` 输出仍是原顺序，检查参数是否漏写引用符号 `&`。
