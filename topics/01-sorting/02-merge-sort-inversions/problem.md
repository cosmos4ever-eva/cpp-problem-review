## 题意

给定一个包含 `8` 个互不相同整数的数组，使用自底向上的归并排序。每轮归并结束后输出当前数组，共输出 `3` 轮；最后输出原数组中的逆序对数量。

逆序对是满足 `i < j` 且 `a[i] > a[j]` 的元素对。

## 核心思路

自底向上的归并排序从长度为 `1` 的有序块开始，每轮把相邻的两个块合并，下一轮将块大小翻倍：

```text
size = 1：合并长度为 1 的相邻块
size = 2：合并长度为 2 的相邻块
size = 4：合并长度为 4 的相邻块
```

外层 `mergesort` 负责枚举每轮的 `size` 和每组的左端点 `l`；内层 `mergecount` 负责合并 `[l, mid]`、`[mid + 1, r]`，同时统计这一轮新产生的逆序对。

## 为什么是 `mid - i + 1`

左右两个区间已经分别有序。当 `a[i] > a[j]` 时，左区间从 `a[i]` 到 `a[mid]` 的所有元素都大于 `a[j]`，因此 `a[j]` 一次形成：

```cpp
mid - i + 1
```

个逆序对。将这个数量加入 `cnt`，不需要逐个枚举左区间剩余元素。

## 原数组与临时数组

合并时从原数组 `a` 中比较左右区间，把正确顺序写入 `tmp`：

```cpp
tmp[k++] = a[i++];
```

合并完成后，再把当前区间复制回 `a`：

```cpp
for(int k = l;k <= r;k ++){
    a[k] = tmp[k];
}
```

这样下一组或下一轮归并读取到的 `a` 才是已经排好序的结果。

## 复杂度

- 时间：`O(n log n)`。
- 临时数组空间：`O(n)`。

## 主要易错点

1. **同时传递 `a` 和 `tmp`。** 使用 `a` 比较，把新顺序写入 `tmp`，完成后必须复制回 `a`。
2. **合并函数返回本次逆序对数量。** 遇到右侧元素更小时执行 `cnt += mid - i + 1`，外层函数负责累加。
3. **内外函数职责分开。** `mergecount` 负责一次合并，`mergesort` 负责各轮循环。
4. **`size` 从 `1` 开始。** 从 `0` 开始时，`size *= 2` 永远还是 `0`，程序会死循环。
5. **左端点每次移动 `2 * size`。** 一次需要处理左右两个相邻块，同时循环上界要确保右半块存在。
6. **最后一组可能不完整。** `mid` 和 `r` 应使用 `min(..., n - 1)`，保证下标不超过 `n - 1`。
