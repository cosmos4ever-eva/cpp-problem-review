## 题意

给定一个包含 `8` 个互不相同整数的数组，使用自底向上的归并排序。每轮归并结束后输出当前数组，共输出 `3` 轮；最后输出原数组中的逆序对数量。

逆序对是满足 `i < j` 且 `a[i] > a[j]` 的元素对。

## 核心思路

自底向上的归并排序从长度为 `1` 的有序块开始，每轮把相邻的两个块合并，下一轮将块大小翻倍：

```text
size = 1：合并长度为 1 的相邻块
size = 2：合并长度为 2 的相邻块
size = 4：合并长度为 4 的相邻块
```

外层 `mergesort` 负责枚举每轮的 `size` 和每组的左端点 `l`；内层 `mergecount` 负责合并 `[l, mid]`、`[mid + 1, r]`，同时统计这一轮新产生的逆序对。

## 为什么是 `mid - i + 1`

左右两个区间已经分别有序。当 `a[i] > a[j]` 时，左区间从 `a[i]` 到 `a[mid]` 的所有元素都大于 `a[j]`，因此 `a[j]` 一次形成：

```cpp
mid - i + 1
```

个逆序对。将这个数量加入 `cnt`，不需要逐个枚举左区间剩余元素。

## 原数组与临时数组

合并时从原数组 `a` 中比较左右区间，把正确顺序写入 `tmp`：

```cpp
tmp[k++] = a[i++];
```

合并完成后，再把当前区间复制回 `a`：

```cpp
for(int k = l;k <= r;k ++){
    a[k] = tmp[k];
}
```

这样下一组或下一轮归并读取到的 `a` 才是已经排好序的结果。

## 变式：递归归并排序模板

递归写法先把闭区间 `[l,r]` 分成 `[l,mid]` 和 `[mid+1,r]`，分别排好序后再合并。

终止条件必须在计算 `mid` 和继续递归之前判断：

```cpp
if (l >= r) return;
```

`l == r` 时区间只有一个元素，已经有序；`l > r` 是空区间。若没有终止条件，单元素区间会不断递归，最终造成栈溢出。

每次合并只需要保存当前区间 `[l1,r2]`，所以临时数组长度为：

```cpp
vector<int> tmp(r2 - l1 + 1);
```

临时数组从 `0` 开始，而原数组当前区间从 `l1` 开始。复制回去时，两个下标的映射是：

```cpp
for (int k = l1; k <= r2; k++) {
    a[k] = tmp[k - l1];
}
```

其中 `k-l1` 会把原数组范围 `l1...r2` 映射为临时数组范围 `0...(r2-l1)`。复制回原数组不能省略，否则父层合并读取的两个子区间仍然不是有序结果。

为了保持稳定性，当左右元素相等时先取左半区间元素，因此比较条件使用 `<=`。

## 复杂度

- 时间：`O(n log n)`。
- 临时数组空间：`O(n)`。

## 主要易错点

1. **同时传递 `a` 和 `tmp`。** 使用 `a` 比较，把新顺序写入 `tmp`，完成后必须复制回 `a`。
2. **合并函数返回本次逆序对数量。** 遇到右侧元素更小时执行 `cnt += mid - i + 1`，外层函数负责累加。
3. **内外函数职责分开。** `mergecount` 负责一次合并，`mergesort` 负责各轮循环。
4. **`size` 从 `1` 开始。** 从 `0` 开始时，`size *= 2` 永远还是 `0`，程序会死循环。
5. **左端点每次移动 `2 * size`。** 一次需要处理左右两个相邻块，同时循环上界要确保右半块存在。
6. **最后一组可能不完整。** `mid` 和 `r` 应使用 `min(..., n - 1)`，保证下标不超过 `n - 1`。
7. **递归归并必须先判断终止条件。** `l>=r` 时立即返回，再计算 `mid` 并递归。
8. **临时数组只开当前区间长度。** 合并 `[l1,r2]` 时长度是 `r2-l1+1`。
9. **复制回原数组时换算下标。** 原数组下标 `k` 对应临时数组下标 `k-l1`，并且复制步骤不能省略。
