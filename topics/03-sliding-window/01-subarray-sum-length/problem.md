# 01 和为 x 的最短与最长连续子数组

## 题意

给定一个全部由正整数组成的数组和正整数 `x`，求元素和恰好等于 `x` 的连续子数组的最短长度和最长长度。如果不存在，输出 `-1 -1`。

数据范围：`1 <= n <= 10^5`，`1 <= a[i] <= 10^4`，`1 <= x <= 10^9`。

## 核心思路

用 `[left, right]` 表示当前窗口，并维护窗口元素和 `sum`：

1. 右端点向右移动，把 `a[right]` 加入窗口。
2. 如果 `sum > x`，不断移动左端点并减去离开窗口的元素。
3. 当 `sum == x` 时，当前窗口就是一个答案，使用 `right - left + 1` 更新最短和最长长度。

因为所有元素都是正数，右端加入元素只会让和增大，左端移出元素只会让和减小。因此，当窗口和过大时，可以确定必须移动左端点，不会漏掉合法答案。

## 为什么每个右端点只需检查一个窗口

缩小窗口直到 `sum <= x` 后：

- 如果 `sum == x`，当前窗口合法；
- 如果 `sum < x`，继续移动左端点只会让和更小，不可能再次等于 `x`。

这依赖 `a[i]` 全为正数。如果数组包含负数，上述单调性不成立，普通滑动窗口就不适用。

## 复杂度

- 时间：`O(n)`。左右指针都最多移动 `n` 次。
- 空间：`O(n)` 用于保存输入数组；如果边读边处理，可以降为与窗口长度相关的空间。

## 对原始代码的整理

原始算法在题目给定的正整数条件下是正确的。整理版主要做了这些调整：

1. 使用 `vector<int>` 代替固定长度全局数组。
2. 使用 `long long` 保存窗口和，增强数值安全性。
3. 直接写 `right - left + 1`，去掉只有一行的 `num` 函数。
4. 使用 `maxLength == 0` 判断是否找到答案，减少一个状态变量。
5. 加入统一的快速输入设置。

## 易错点

1. 连续子数组长度是 `right - left + 1`，不能漏掉 `+1`。
2. 收缩窗口必须使用 `while`，因为只移动一次后窗口和可能仍然大于 `x`。
3. 该方法成立的关键是所有数组元素均为正数。
4. 不存在答案时输出两个 `-1`。

## 复习问题

1. 为什么这里必须使用 `while (sum > x)`，不能只用 `if`？
2. 如果数组允许出现 `0`，一个固定右端点是否可能对应多个和为 `x` 的窗口？
3. 如果数组允许出现负数，应考虑用什么方法替代这个滑动窗口？
