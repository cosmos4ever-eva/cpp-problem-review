## 题意

给定一个只包含小写字母的字符串，可以进行任意次左循环或右循环移动。求所有能够得到的不同字符串中字典序第二大的字符串。

字典序相同的结果只算同一个字符串，题目保证第二大字符串存在。

## 枚举所有循环结果

一次左循环移动可以写成：

```cpp
s.push_back(s[0]);
s.erase(s.begin());
```

第一句把原来的首字符追加到字符串末尾，第二句删除原来的首字符。例如：

```text
abcd -> abcda -> bcda
```

长度为 `n` 的字符串连续左移 `n` 次会回到原字符串，所以循环 `n` 次能够覆盖全部循环位置。任意次右移得到的结果也属于同一组循环排列，不需要另行枚举。

代码虽然先左移再比较，但第 `n` 次左移会回到原字符串，因此原字符串不会被漏掉。

## `push_back` 和 `erase`

```cpp
s.push_back(s[0]);
```

`s[0]` 的类型是 `char`，而 `string::push_back` 每次添加一个字符，所以可以直接传入。

```cpp
s.erase(s.begin());
```

这里只传入一个迭代器，表示删除该位置的一个字符。如果传入两个迭代器，则表示删除左闭右开的整段区间：

```cpp
container.erase(first,last);
```

## 字符串的字典序比较

`string` 可以直接使用 `<`、`>` 等运算符比较字典序：

```cpp
s > firstMax
s < firstMax
```

C++ 会从左到右寻找第一对不同字符，并用这一对字符决定大小。题目中的所有循环结果长度相同，因此直接比较即可。

## 维护最大和第二大

程序使用：

```cpp
string firstMax = s,secondMax = "";
```

- `firstMax` 保存当前最大的不同字符串；
- `secondMax` 保存当前第二大的不同字符串。

如果当前字符串超过最大值：

```cpp
if(s > firstMax){
    secondMax = firstMax;
    firstMax = s;
}
```

先把旧最大值降为第二大，再用当前字符串更新最大值。赋值顺序不能颠倒，否则会丢失旧最大值。

如果当前字符串严格位于最大与第二大之间：

```cpp
if(s < firstMax && s > secondMax) secondMax = s;
```

就用它更新第二大值。条件使用严格小于和严格大于，因此与最大值或第二大值相等的重复字符串不会再次计入排名。

## 示例过程

对于：

```text
baca
```

循环结果为：

```text
acab
caba
abac
baca
```

其中最大值是 `caba`，第二大值是 `baca`。

## 单引号与双引号

- 单引号表示一个字符，例如 `'a'`，类型为 `char`；
- 双引号表示字符串，例如 `"a"`、`"abc"`，可用于初始化或比较 `string`；
- 空字符串写成 `""`，不存在空字符 `''`；
- `s[i]` 和 `s[0]` 都是单个字符，传给 `push_back` 时不需要双引号。

## 复杂度

循环次数为 `n`。每次从开头 `erase` 需要移动后续字符，字符串比较最坏也需要扫描整个字符串，因此：

- 时间复杂度：`O(n^2)`；
- 额外空间复杂度：`O(n)`，用于保存最大与第二大字符串。

## 主要易错点

1. 连续左移 `n` 次已经能够覆盖所有循环位置，不需要同时枚举右移。
2. `string` 可以直接使用 `<`、`>` 比较字典序。
3. `push_back` 添加单个字符，`erase(s.begin())` 删除单个字符。
4. 出现新最大值时，要先保存旧最大值，再更新 `firstMax`。
5. 第二大必须与最大值严格不同，比较条件要排除相等字符串。
