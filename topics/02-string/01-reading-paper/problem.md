## 题意

一个单词中的某个字母可能被连续写若干次。需要把每一段连续相同的字母压缩为一个字母，再找出压缩后出现次数最多的单词；如果频率相同，输出在输入中最早出现的压缩结果。

数据范围：`1 <= n <= 1000`，每个单词长度为 `1` 到 `50`。

## 核心思路

1. 逐个扫描单词，只在当前字符与压缩结果的最后一个字符不同时加入它。
2. 使用 `unordered_map<string, int>` 统计每个压缩结果的出现次数。
3. 统计完成后，再按原输入顺序扫描压缩结果。
4. 只有当前频率严格大于已有最大值时才更新答案；频率相等时不更新，因此自然保留最早出现的结果。

例如，`coool` 会依次保留 `c`、`o`、`l`，得到 `col`；`aabbaa` 会得到 `aba`。

## 为什么需要第二次扫描

所有频率只有在读取完全部单词后才确定。第二次按照输入顺序扫描，可以同时满足“频率最大”和“相同时最早出现”。

原始代码的选择答案部分是正确的。不过，最后一个循环只是在找到任意最高频元素后输出已经算好的 `answer`，并没有再次参与选择，可以直接写成 `cout << answer`。

## 复杂度

设所有输入字符串的总长度为 `L`：

- 压缩和计数：平均 `O(L)`
- 按输入顺序选择答案：平均 `O(n)` 次哈希查询
- 空间：`O(L)`

## 易错点

1. 只能合并连续相同字符；`abca` 中的两个 `a` 不能合并。
2. 原始写法直接访问 `s[0]`，依赖题目保证字符串非空。
3. 频率相同时不能更新答案，否则可能选到更晚出现的单词。
4. 不要一边读入一边只根据“当前累计次数”确定最终最早答案，因为较早的单词可能稍后才追平。
