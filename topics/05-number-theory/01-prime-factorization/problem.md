## 题意

给定一个正整数 `n`，将它分解为若干质因子的乘积。按照质因子从小到大的顺序，每行输出质因子及其指数。

数据范围：`2 <= n <= 10^6`。

## 核心思路

先用埃氏筛生成不超过 `sqrt(n)` 的质数表，再依次使用这些质数试除：

1. 如果当前质数能够整除 `remaining`，就反复相除并统计指数。
2. 当当前质数已经大于 `sqrt(remaining)` 时，可以结束试除。
3. 循环结束后，如果 `remaining > 1`，它一定是一个尚未输出的质因子，指数为 `1`。

建立质数表不是分解单个整数的唯一方法，也可以直接枚举整数试除；但使用质数表能够跳过所有合数，并为以后处理多个数打下基础。

## 为什么只筛到根号

如果 `n` 是合数，那么它至少有一个不超过 `sqrt(n)` 的质因子。将所有较小质因子除尽后，剩余值只可能是 `1` 或一个大于平方根的质数，因此不需要把质数表建立到 `n`。

例如 `n = 26`：只需尝试质数 `2、3、5`。除去 `2` 后剩余 `13`，循环结束时将 `13 1` 单独加入结果。

## 埃氏筛

```cpp
for (int i = 2; i <= limit / i; ++i) {
    if (isPrime[i]) {
        for (int multiple = i * i; multiple <= limit; multiple += i) {
            isPrime[multiple] = false;
        }
    }
}
```

从 `i * i` 开始标记，是因为更小的倍数已经被较小质因子标记过。内层循环必须标记完所有倍数，不能在标记第一个倍数后 `break`。

## 复杂度

- 埃氏筛：时间 `O(sqrt(n) log log sqrt(n))`，空间 `O(sqrt(n))`。
- 试除过程：最多遍历不超过 `sqrt(n)` 的所有质数。

## 主要易错点

1. **筛法内层循环不能提前 `break`。** 原始代码只标记了 `2 * i`，没有标记 `3 * i、4 * i……`，因此得到的列表中会混入合数。
2. **不必建立到 `n` 的质数表。** 本题筛到 `sqrt(n)` 即可，能够减少时间和空间。
3. **不要漏掉最后的剩余值。** 试除结束后若 `remaining > 1`，必须输出 `remaining 1`。当输入本身是质数时，这一步就是唯一的输出。
4. **用除法形式控制上界。** `prime <= remaining / prime` 不会产生 `prime * prime` 的乘法溢出。
5. **质数表应按常量引用传递。** 使用 `const vector<int>& primes` 可以避免复制整个数组。

## 对原始代码的整理

原始代码已经采用“先生成候选质数，再进行分解”的整体结构。整理版修正了筛法中的提前退出问题，将筛选范围缩小到 `sqrt(n)`，并补充对最后一个剩余质因子的处理。
