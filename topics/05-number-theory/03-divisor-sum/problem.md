## 题意

给定一个正整数 `n`，求 `n` 的所有正约数之和。

## 核心思路

先对 `n` 做质因数分解。若：

```text
n = p1^c1 * p2^c2 * ... * pk^ck
```

一个约数可以从每个质因数 `pi` 中独立选择 `0...ci` 个，因此所有约数之和是：

```text
(p1^0 + p1^1 + ... + p1^c1)
* (p2^0 + p2^1 + ... + p2^c2)
* ...
* (pk^0 + pk^1 + ... + pk^ck)
```

这与“约数个数”的结构完全对应：约数个数只统计每个质因数有多少种指数选择，得到 `(ci + 1)`；约数和则把这些选择所代表的实际幂次全部相加，再将各组乘起来。

例如：

```text
12 = 2^2 * 3^1
```

所以：

```text
约数和 = (2^0 + 2^1 + 2^2) * (3^0 + 3^1)
       = (1 + 2 + 4) * (1 + 3)
       = 28
```

## `count_one` 如何计算等比和

`count_one(prime, cnt)` 计算：

```text
1 + prime + prime^2 + ... + prime^cnt
```

代码从 `total = 1` 开始，重复执行：

```cpp
total = total * prime + 1;
```

若 `cnt = 3`，状态依次是：

```text
1
prime + 1
prime^2 + prime + 1
prime^3 + prime^2 + prime + 1
```

因此循环 `cnt` 次后，恰好得到从 `prime^0` 到 `prime^cnt` 的幂次和。这种写法不需要单独维护当前幂次。

## 为什么只筛到原数的平方根

若 `n` 是合数，它至少有一个不超过 `sqrt(n)` 的质因数。因此先建立到原始 `n` 平方根的质数表，再用这些质数反复试除即可。

所有小质因数除尽后，如果 `remaining > 1`，剩余值一定是指数为 `1` 的质数。它对应的幂次和是：

```text
remaining^0 + remaining^1 = 1 + remaining
```

所以最后需要执行：

```cpp
sum *= remaining + 1;
```

## 核心函数思路

- `getPrime(n)`：使用筛法生成不超过 `n` 的质数，供试除使用。
- `count_one(prime, cnt)`：利用 `total = total * prime + 1` 计算一个质因数对应的幂次和。
- `countsum(n)`：分解 `n`，统计每个质因数的指数，将各个幂次和相乘，并处理最后剩余的大质因数。
- `main()`：读入 `n`，调用 `countsum` 并输出答案。

## 复杂度

- 质数表只建立到 `sqrt(n)`。
- 试除只枚举不超过 `sqrt(n)` 的质数。
- 额外空间用于筛法标记数组和质数表。

## 主要易错点

1. 约数和不是 `(指数 + 1)` 的乘积；那是约数个数公式。约数和必须计算每个质因数的幂次和，再把各组相乘。
2. `count_one` 的初值必须为 `1`，因为公式包含 `prime^0 = 1`。
3. 递推应写成 `total = total * prime + 1`。循环 `cnt` 次后才得到 `1 + prime + ... + prime^cnt`。
4. 试除结束后若 `remaining > 1`，必须乘入 `remaining + 1`，否则输入为质数或留有大质因数时会漏算。
5. 答案和中间的幂次乘法可能超过 `int`，更稳妥的实现应使用 `long long`。
6. 原代码中的 `string` 和 `unordered_map` 没有使用，不影响运行，但整理时可以删除，减少干扰。

## 调试方法

1. 测试 `n = 1`，答案应为 `1`，用于检查初值。
2. 测试质数 `n = 7`，答案应为 `1 + 7 = 8`，用于检查剩余质因数。
3. 测试质数幂 `n = 8 = 2^3`，答案应为 `1 + 2 + 4 + 8 = 15`，用于检查 `count_one`。
4. 测试多个质因数 `n = 12 = 2^2 * 3`，答案应为 `28`，用于检查各组相乘。
5. 在 `countsum` 中临时打印 `prime、cnt、remaining、count_one(prime,cnt)、sum`，定位第一处与手算不一致的状态。
