## 题意

给定两个正整数 `a` 和 `b`，求它们的最大公约数。

## 辗转相除法

最大公约数满足：

```text
gcd(a, b) = gcd(b, a % b)
```

原因是 `a` 可以写成：

```text
a = q * b + r
```

其中 `r = a % b`。能够同时整除 `a` 和 `b` 的数，也一定能整除 `r`；能够同时整除 `b` 和 `r` 的数，也一定能整除 `a`。因此两组数的公约数相同，最大公约数也相同。

代码不断把问题缩小：

```cpp
return gcd(b,a % b);
```

第二个参数会不断变成更小的余数，直到余数为 `0`。

## 递归终止条件

```cpp
if(b == 0) return a;
```

任何正整数 `a` 与 `0` 的最大公约数都是 `a`。因此当第二个参数变成 `0` 时，当前的 `a` 就是最终答案。

例如计算 `gcd(18, 12)`：

```text
gcd(18, 12)
→ gcd(12, 6)
→ gcd(6, 0)
→ 6
```

## 不需要提前区分大小

即使输入满足 `a < b`，代码仍然正确。例如：

```text
gcd(12, 18)
→ gcd(18, 12)
→ gcd(12, 6)
→ gcd(6, 0)
→ 6
```

第一次计算时 `12 % 18 == 12`，参数会自然交换到合适的顺序，所以不需要预先使用 `max`、`min` 或 `swap`。

## 递归思想

辗转相除法通过关系：

```text
大问题 gcd(a,b)
→ 更小的同类问题 gcd(b,a%b)
```

不断缩小问题规模，直到到达 `b == 0` 的基础情况。这是典型的递归思想。

同一个算法也能使用 `while` 循环实现，但当前代码直接用递归关系表达，结构更加接近数学定义。

## 复杂度

- 时间复杂度为 `O(log(min(a,b)))`。
- 递归调用栈为 `O(log(min(a,b)))`。

## 主要易错点

1. 不需要提前判断 `a` 和 `b` 的大小，递归过程会自然处理参数顺序。
2. 递归关系是 `gcd(b, a % b)`，两个新参数的位置不能写反。
3. 终止条件是 `b == 0`，此时返回 `a`。
4. 辗转相除法本质上不断转化为规模更小的同类问题，是递归思想；但也可以改写为循环。
