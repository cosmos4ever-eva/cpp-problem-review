## 题意

给定两个整数 `a` 和 `b`，其中：

```text
g(a,b) = (b+1) * (b+2) * ... * a = a! / b!
```

求 `g(a,b)` 的末尾有多少个连续的 `0`。

## 核心思路

一个末尾零来自因子：

```text
10 = 2 * 5
```

所以需要分别统计 `g(a,b)` 中质因子 `2` 和 `5` 的总数量，答案是两者的较小值：

```cpp
min(count2,count5)
```

又因为：

```text
a! = b! * g(a,b)
```

所以 `g(a,b)` 中质因子 `p` 的数量等于：

```text
a! 中 p 的数量 - b! 中 p 的数量
```

## 通过 `n / p` 逐层统计

`n!` 中质因子 `p` 的总数量可以写成：

```text
floor(n/p) + floor(n/p^2) + floor(n/p^3) + ...
```

对应循环是：

```cpp
long long cnt = 0;
while(n > 0){
    n /= p;
    cnt += n;
}
```

每一层的意义如下：

1. 第一次 `n /= p`：统计 `1...n` 中所有至少包含一个因子 `p` 的数；
2. 第二次 `n /= p`：统计所有还额外包含第二个因子 `p` 的数，也就是原来能被 `p^2` 整除的数；
3. 第三次继续统计 `p^3` 带来的第三个因子；
4. 依此类推，直到商变成 `0`。

因此，这个循环记录的是不超过原始 `n` 的所有整数中，质因子 `p` 出现次数的总和，而不是只统计有多少个数能够被 `p` 整除。

例如 `10!` 中因子 `2` 的数量为：

```text
10/2 + 10/4 + 10/8 = 5 + 2 + 1 = 8
```

## 为什么用阶乘结果相减

逐个遍历 `[b+1,a]` 的方法是：

```text
vp(b+1) + vp(b+2) + ... + vp(a)
```

阶乘相减的方法是：

```text
vp(a!) - vp(b!)
```

由于 `a! = b! * (b+1) * ... * a`，两者完全相等。阶乘方法不需要遍历整个区间，只需分别进行若干次除法，因此速度更快。

例如 `a = 6、b = 3`：

```text
g(6,3) = 4 * 5 * 6 = 120
```

因子 `2` 的数量为：

```text
count(6!,2) - count(3!,2) = 4 - 1 = 3
```

因子 `5` 的数量为 `1`，所以末尾零数量为 `min(3,1) = 1`。

## 复杂度

- 逐个遍历区间的解法约为 `O((a-b) log a)`。
- 阶乘质因数计数只进行连续除法，约为 `O(log a + log b)`。
- 两种解法都只需要 `O(1)` 额外空间。

## 主要易错点

1. 只统计 `i % 5 == 0` 不够，因为 `25 = 5^2`、`125 = 5^3` 会贡献多个因子 `5`。
2. `a! / b!` 中因子 `p` 的数量是 `count(a!,p) - count(b!,p)`，不是两个普通整数 `a`、`b` 自身的因子数量相减。
3. `n /= p; cnt += n;` 的循环依次统计 `p、p^2、p^3……` 带来的每一层额外贡献。
4. `a! / b!` 中因子 `2` 不一定总比因子 `5` 多，所以仍应分别统计并取 `min(count2,count5)`。
5. `min` 的标准头文件是 `<algorithm>`。
