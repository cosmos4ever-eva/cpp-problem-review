## 题意

给定一个正整数 `n`，求 `n` 的正约数个数。

数据范围：`2 <= n <= 10^6`。

## 核心思路

先把 `n` 质因数分解。若：

```text
n = p1^a1 * p2^a2 * ... * pk^ak
```

那么一个约数可以分别选择每个质因数的 `0...ai` 次方，因此约数个数为：

```text
(a1 + 1) * (a2 + 1) * ... * (ak + 1)
```

代码用 `cnt` 统计当前质因数的指数，除尽后直接执行：

```cpp
if(cnt) sum *= (cnt + 1);
```

每个质因数的次数可以立即参与答案计算，因此不需要建立哈希表保存全部质因数及其次数。

## 筛法边界为什么取等号

质数表包含上界 `n`，所以外层循环应写：

```cpp
for(int i = 2;i <= n;i++)
```

标记倍数时，乘积恰好等于上界也必须被标记，因此内层循环应写：

```cpp
for(int j = 2;j <= n / i;j++)
```

例如上界为 `4`、`i = 2` 时，需要让 `j = 2` 进入循环并标记 `isPrime[4] = false`。如果写成 `< n / i`，`4` 会被错误地保留在质数表中。

## 为什么质数表只建立到根号

若 `n` 是合数，它至少有一个不超过 `sqrt(n)` 的质因数。因此本题只需建立到原始 `n` 的平方根的质数表：

```cpp
vector<int> primes = getPrime(sqrt(n));
```

把表中的所有质因数除尽后，如果 `div > 1`，剩余的 `div` 一定是一个大于原始平方根的质数，而且指数只能为 `1`。它对约数个数的贡献是：

```text
1 + 1 = 2
```

这个 `2` 是对已有结果的贡献，所以应写：

```cpp
if(div > 1) sum *= 2;
```

不能写成 `sum = 2`，否则会覆盖前面质因数已经产生的约数个数。

## 示例

```text
12 = 2^2 * 3^1
```

因此约数个数为：

```text
(2 + 1) * (1 + 1) = 6
```

再看只筛到平方根后存在剩余质数的情况：

```text
14 = 2^1 * 7^1
```

处理质数表中的 `2` 后，`sum = 2`、`div = 7`。最后的 `7` 贡献一个因子 `2`，所以答案是 `2 * 2 = 4`。

## 复杂度

- 质数表只建立到 `sqrt(n)`。
- 质因数试除只遍历不超过 `sqrt(n)` 的质数。
- 空间用于保存不超过 `sqrt(n)` 的质数表和筛法标记数组。

## 主要易错点

1. 筛法外层和内层的上界都要包含等号，避免漏掉恰好等于上界的数。
2. 约数个数不是所有质因数指数的和，而是所有 `(指数 + 1)` 的乘积。
3. 每得到一个质因数的指数就可以直接更新答案，不需要使用哈希表保存。
4. 质数表只需建立到原始 `n` 的平方根，可以减少时间和空间。
5. 试除结束后若 `div > 1`，它是指数为 `1` 的剩余质因数，应执行 `sum *= 2`，不能用 `sum = 2` 覆盖已有结果。
