## 题意

给定一个整数 `a`，求方程

```text
x^3 + x^2 + x = a
```

的根，并将结果保留两位小数。

## 核心思路

令 `f(x) = x^3 + x^2 + x`。这个函数在实数范围内严格递增，因此可以在包含答案的区间上进行实数二分：

1. 计算 `mid = (l + r) / 2`。
2. 如果 `f(mid) > a`，说明根在左侧，令 `r = mid`。
3. 否则根在右侧，令 `l = mid`。
4. 当 `r - l <= EPS` 时，区间已经足够小，可以输出近似结果。

## 实数二分框架

```cpp
while(r - l > EPS){
    mid = (l+r)/2;
    if(mid * mid * mid + mid * mid + mid > a) r = mid;
    else l = mid;
}
```

与整数二分不同，实数端点通常不会恰好相遇，所以终止条件是区间长度达到规定精度，而不是 `l == r`。

## 复杂度

- 时间：`O(log((r-l)/EPS))`。
- 额外空间：`O(1)`。

## 主要易错点

1. **设置合适的精度。** 要求保留两位小数时，内部计算应更精确，例如使用 `EPS = 1e-6`。
2. **上下界、中点和精度都使用浮点类型。** 整理版把上下界明确写成 `-100.0` 和 `100.0`。
3. **二分方向依赖单调性。** 因为 `f(x)` 递增，所以 `f(mid) > a` 时才能确定向左查找。
4. **初始区间必须包含根。** 本题使用 `[-100.0, 100.0]`，前提是题目数据保证根位于该范围内。
5. **输出格式与搜索精度不同。** `printf("%.2f", mid)` 只控制显示两位小数，真正的计算精度由 `EPS` 控制。

## 对原始代码的整理

原始代码的算法和结构正确。整理版只把上下界字面量从 `-100`、`100` 改为 `-100.0`、`100.0`，让所有区间数据均为浮点数的意图更明确，其余代码保持不变。
