## 题意

给定若干树桩坐标 `c` 和陷阱坐标 `d`。一个树桩的安全距离是它到最近陷阱的距离，求所有树桩安全距离的最大值。

## 核心思路

先将陷阱坐标 `d` 排序。对于每个树桩坐标 `cite`：

1. 如果它位于第一个陷阱左侧，最近距离是 `d[0] - cite`。
2. 如果它位于最后一个陷阱处或右侧，最近距离是 `cite - d[m - 1]`。
3. 否则二分找到最后一个满足 `d[answer] <= cite` 的位置。树桩左右两侧最近的陷阱就是 `d[answer]` 和 `d[answer + 1]`，取两个距离的较小值。

最后用 `max_dis` 维护所有树桩安全距离中的最大值。

## 二分查找相邻候选

```cpp
if(d[mid] <= cite){
    answer = mid;
    l = mid + 1;
}
else r = mid - 1;
```

排序后，比目标值更远的其他陷阱不可能成为最近陷阱，因此只需比较边界两侧的两个相邻候选：

```cpp
min(cite - d[answer], d[answer+1] - cite)
```

## 复杂度

- 排序陷阱：`O(m log m)`。
- 每个树桩进行一次二分：`O(log m)`，共 `O(n log m)`。
- 总时间：`O(m log m + n log m)`。
- 保存输入数组：`O(n + m)`。

## 主要易错点

1. **安全计算中点。** 使用 `mid = l + (r - l) / 2`，避免 `l + r` 可能溢出。
2. **按常量引用传递数组。** `const vector<int>& d` 不会复制整个陷阱数组，也不会在函数中修改它。
3. **右边界必须包含等号。** 应写 `c[i] >= d[m - 1]`。若目标等于最后一个陷阱却进入 `finddis`，`answer` 会等于 `m - 1`，随后访问 `d[answer + 1]` 将发生数组越界，而不是栈溢出。
4. **按下标输入前要真正创建元素。** 使用 `resize` 或在构造时指定大小；`reserve` 只改变容量，不能让 `d[i]` 成为有效元素。
5. **只比较左右相邻位置。** 二分找到最后一个 `<= cite` 的陷阱后，答案只能来自它或下一个陷阱。
