## 题意

一本教材有 `n` 个章节，第 1 章从第 1 页开始，并给出第 2 章到第 `n` 章的起始页码。对于每个重点页码 `note`，输出它所属的章节。

## 核心思路

章节起始页码严格递增。一个页码所属的章节，就是最后一个满足下面条件的章节：

```cpp
start[chapter] <= note
```

使用二分查找寻找这个最靠右的位置，并用 `answer` 保存当前已经找到的可行位置：

```cpp
if(start[mid] <= note){
    answer = mid;
    l = mid + 1;
}
else r = mid - 1;
```

当条件成立时，`mid` 可能是答案，但右侧也可能还有满足条件的位置，因此先记录 `mid`，再继续向右查找。

## 为什么不检查下一个位置

下面的判断虽然直观，但存在越界风险：

```cpp
start[mid] <= note && start[mid+1] > note
```

当 `mid == n` 时，`start[mid + 1]` 已经超出数组范围。维护 `answer` 可以只访问当前有效位置，并在循环结束后得到正确边界。

## 复杂度

- 建立章节起始页数组：`O(n)`。
- 每次查询：`O(log n)`，全部查询为 `O(q log n)`。
- 空间：`O(n + q)`。

## 主要易错点

1. **不要直接访问 `start[mid + 1]`。** `mid` 可能已经是最后一个章节下标。
2. **寻找的是最后一个满足条件的位置。** 条件成立后要记录 `answer`，并令 `l = mid + 1` 继续向右搜索。
3. **第 1 章的起始页是已知的。** 使用从 `1` 开始的章节编号时，应设置 `start[1] = 1`。
4. **数组大小要与下标一致。** 章节编号范围是 `1` 到 `n`，因此创建 `vector<int> start(n + 1)`。
