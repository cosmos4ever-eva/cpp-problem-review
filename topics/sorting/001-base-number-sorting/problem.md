## 题意

输入若干个用不同进制表示的非负整数，按照它们对应的十进制值从小到大排序。数值相同时保持输入顺序；输出时保留原来的进制和数字字符串，包括前导零。

数据范围：`1 <= n <= 2 * 10^4`，`2 <= b <= 16`，转换后的值不超过 `10^18`。

## 核心思路

逐位扫描数字字符串，用秦九韶形式完成进制转换：

```text
value = value * base + digit
```

转换后使用稳定排序按照 `value` 升序排列。由于排序是稳定的，十进制值相等的元素仍然保持输入顺序。

## 复杂度

- 进制转换：`O(L)`，其中 `L` 是所有数字字符串的总长度
- 排序：`O(n log n)`
- 空间：`O(n)`

## 易错点

1. `A` 到 `F` 分别表示十进制的 `10` 到 `15`。
2. 输出时使用原字符串，不能输出转换后的值，否则会丢失前导零。
3. 十进制值相同时必须保持输入顺序。
4. 最大值达到 `10^18`，需要使用 `long long`。
