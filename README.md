# C++ Problem Review

一个以复习为目的的 C++ 做题仓库。每道题保留核心思路、易错点、复杂度和可运行代码。

## 目录结构

每个知识点类别有独立编号，题目再在类别内部从 `01` 开始编号：

```text
topics/
├─ 01-sorting/
│  └─ 01-base-number-sorting/
├─ 02-string/
│  └─ 01-reading-paper/
└─ 03-two-pointers/
   ├─ 01-subarray-sum-length/
   └─ 02-set-difference-iii/
```
